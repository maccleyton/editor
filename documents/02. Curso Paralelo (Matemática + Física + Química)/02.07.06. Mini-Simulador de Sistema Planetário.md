## 🎯 **Objetivo:**

Simular interações gravitacionais múltiplas.

**Equação de Newton para cada corpo:**

$\vec a_i = \sum_{j\ne i} G \frac{m_j (\vec r_j - \vec r_i)}{|\vec r_j-\vec r_i|^3}$

**Implementação simples com Euler em Python (2 corpos como exemplo):**

```python
import numpy as np
import matplotlib.pyplot as plt

G = 6.674e-11
m1 = 5.972e24  # Terra
m2 = 7.348e22  # Lua
r1 = np.array([0.,0.])
r2 = np.array([384400000.,0.])
v1 = np.array([0.,0.])
v2 = np.array([0.,1022.])  # velocidade média da Lua

dt = 3600  # 1h
steps = 24*30  # 30 dias

r1_hist = []
r2_hist = []

for _ in range(steps):
    r = r2 - r1
    dist = np.linalg.norm(r)
    a1 = G*m2*r/dist**3
    a2 = -G*m1*r/dist**3

    v1 += a1*dt
    v2 += a2*dt
    r1 += v1*dt
    r2 += v2*dt

    r1_hist.append(r1.copy())
    r2_hist.append(r2.copy())

r1_hist = np.array(r1_hist)
r2_hist = np.array(r2_hist)

plt.plot(r1_hist[:,0], r1_hist[:,1], label='Terra')
plt.plot(r2_hist[:,0], r2_hist[:,1], label='Lua')
plt.legend()
plt.axis('equal')
plt.show()
```
