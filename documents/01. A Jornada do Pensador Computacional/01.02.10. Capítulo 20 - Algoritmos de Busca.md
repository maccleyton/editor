## 20.1 Busca Linear

- Percorre sequencialmente todos os elementos para encontrar o valor.
- Simples, mas pode ser ineficiente para grandes listas.

```python
def busca_linear(lista, x):
    for i, elemento in enumerate(lista):
        if elemento == x:
            return i
    return -1

*# Exemplo*
lista = [3, 7, 1, 9, 2]
print(busca_linear(lista, 9))  *# Saída: 3*
print(busca_linear(lista, 5))  *# Saída: -1*
```

## 20.2 Busca Binária

- Requer lista ordenada.
- Divide o espaço de busca repetidamente pela metade.
- Complexidade $O(\log n)$.

```python
def busca_binaria(lista, x):
    esquerda, direita = 0, len(lista) - 1
    while esquerda <= direita:
        meio = (esquerda + direita) // 2
        if lista[meio] == x:
            return meio
        elif lista[meio] < x:
            esquerda = meio + 1
        else:
            direita = meio - 1
    return -1

*# Exemplo*
lista = [1, 2, 3, 7, 9]
print(busca_binaria(lista, 7))  *# Saída: 3*
print(busca_binaria(lista, 5))  *# Saída: -1*
```

## 20.3 Busca Ternária

- Também para listas ordenadas.
- Divide a lista em três partes e descarta duas delas.
- Útil para arrays com função unimodal para encontrar máximo mínimo.
- Complexidade ainda $O(\log n)$.

```python
def busca_ternaria(lista, x):
    esquerda, direita = 0, len(lista) - 1
    while esquerda <= direita:
        terco1 = esquerda + (direita - esquerda) // 3
        terco2 = direita - (direita - esquerda) // 3
        if lista[terco1] == x:
            return terco1
        if lista[terco2] == x:
            return terco2
        if x < lista[terco1]:
            direita = terco1 - 1
        elif x > lista[terco2]:
            esquerda = terco2 + 1
        else:
            esquerda = terco1 + 1
            direita = terco2 - 1
    return -1

*# Exemplo*
lista = [1, 2, 3, 7, 9]
print(busca_ternaria(lista, 7))  *# Saída: 3*
print(busca_ternaria(lista, 5))  *# Saída: -1*
```

## 20.4 Hashing

### 20.4.1 Funções Hash

- Transformam dados arbitrários em índices numéricos para armazenamento em tabela hash.
- Boa função hash minimiza colisões e distribui uniformemente.

### 20.4.2 Tratamento de Colisões

- Pode usar encadeamento (listas em cada posição) ou endereçamento aberto (tentar outra posição).

### 20.4.3 Hash Tables

- Estrutura associativa que permite inserção, busca e remoção em tempo próximo de $O(1)$.
- Muito usada em dicionários, caches, bancos de dados.

## 20.5 Árvores de Busca

---

### 20.5.1 Binary Search Trees (BST)

- Estrutura de dados em forma de árvore binária onde para cada nó:
    - Todos os elementos na subárvore esquerda são menores que o nó.
    - Todos os elementos na subárvore direita são maiores que o nó.
- Facilita busca, inserção e remoção com complexidade média $O(\log n)$, porém pior caso $O(n)$ se a árvore estiver desbalanceada.
- Operações básicas: busca, inserção, remoção, percurso (pré-ordem, em-ordem, pós-ordem).

---

### 20.5.2 AVL Trees

- Variante balanceada da BST que garante altura balanceada.
- Define fator de balanceamento para cada nó (altura da subárvore esquerda – direita).
- Opera rotações simples e duplas para manter o balanceamento após inserções e remoções.
- Tempo garantido em $O(\log n)$ para busca, inserção e remoção.
- Aplicável quando desempenho consistente em buscas é essencial.

---

### 20.5.3 B-Trees

- Árvore balanceada com múltiplos filhos por nó, muito usada em sistemas de arquivos e bancos de dados.
- Cada nó pode conter vários elementos e referências a vários filhos.
- Mantém todos os nós folha na mesma profundidade.
- Otimizada para armazenamento em disco, reduzindo acessos de leitura.

### Exemplo Python para BST

Aqui está uma implementação em Python para uma Árvore Binária de Busca (Binary Search Tree - BST), incluindo inserção e busca para começar:

```python
class Node:
    def __init__(self, key, value=None):
        self.key = key
        self.value = value
        self.left = None
        self.right = None

class BinarySearchTree:
    def __init__(self):
        self.root = None

    def insert(self, key, value=None):
        if self.root is None:
            self.root = Node(key, value)
        else:
            self._insert(self.root, key, value)
    
    def _insert(self, current_node, key, value):
        if key < current_node.key:
            if current_node.left is None:
                current_node.left = Node(key, value)
            else:
                self._insert(current_node.left, key, value)
        elif key > current_node.key:
            if current_node.right is None:
                current_node.right = Node(key, value)
            else:
                self._insert(current_node.right, key, value)
        else:
            *# Se chave já existe, pode atualizar o valor*
            current_node.value = value

    def search(self, key):
        return self._search(self.root, key)
    
    def _search(self, current_node, key):
        if current_node is None:
            return None
        if key == current_node.key:
            return current_node.value
        elif key < current_node.key:
            return self._search(current_node.left, key)
        else:
            return self._search(current_node.right, key)

*# Exemplo de uso*
bst = BinarySearchTree()
bst.insert(8)
bst.insert(3)
bst.insert(10)
bst.insert(1)
bst.insert(6)

print(bst.search(6))  *# Saída: None (valor não especificado)*
print(bst.search(7))  *# Saída: None (não encontrado)*
```
