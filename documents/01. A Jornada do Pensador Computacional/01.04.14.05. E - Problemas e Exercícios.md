**Problema 16: Subarray com Soma Máxima (Kadane)**

```bash
Descrição: Encontre o subarray contíguo com a maior soma.

Entrada: [-2,1,-3,4,-1,2,1,-5,4]
Saída: 6 (subarray [4,-1,2,1])

Algoritmo de Kadane:
max_ending_here = max_so_far = arr[0]
for i in range(1, n):
    max_ending_here = max(arr[i], max_ending_here + arr[i])
    max_so_far = max(max_so_far, max_ending_here)

Extensões:
- Retornar os índices do subarray
- Versão para arrays 2D
- Subarray com produto máximo
```

**Problema 22: Problema da Mochila 0/1**

```bash

Entrada:

Saída: 9 (items de peso 3 e 4, valores 4 e 5)

DP State: dp[i][w] = valor máximo usando primeiros i items com peso ≤ w

- Space: O(W) em vez de O(nW)
- Early termination
- Branch and bound para grandes instâncias
```

## E.5 Soluções Comentadas

### Solução Detalhada: Problema 8 (LIS)

**Análise do Problema:**

Encontrar a subsequência crescente mais longa em um array requer decidir, para cada elemento, se incluí-lo na subsequência ótima.

**Abordagem 1: Programação Dinâmica O(n²)**

```python
def lengthOfLIS(nums):
    """
    DP State: dp[i] = length of LIS ending at index i
    Transition: dp[i] = max(dp[j] + 1) for all j < i where nums[j] < nums[i]
    """
    if not nums:
        return 0
    
    n = len(nums)
    dp = [1] * n  *# Every element forms LIS of length 1*
    
    for i in range(1, n):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    
    return max(dp)

*# Time: O(n²), Space: O(n)# Works for n ≤ 2500 typically*
```

**Abordagem 2: Binary Search O(n log n)**

```python
def lengthOfLIS_optimized(nums):
    """
    Key insight: Maintain array 'tails' where tails[i] is the smallest 
    tail element of all increasing subsequences of length i+1.
    
    tails is always sorted, so we can use binary search.
    """
    if not nums:
        return 0
    
    tails = []
    
    for num in nums:
        *# Binary search for position to insert/update*
        left, right = 0, len(tails)
        while left < right:
            mid = (left + right) // 2
            if tails[mid] < num:
                left = mid + 1
            else:
                right = mid
        
        *# If num is larger than all elements, append*
        if left == len(tails):
            tails.append(num)
        else:
            *# Replace element to maintain smallest tails*
            tails[left] = num
    
    return len(tails)

*# Time: O(n log n), Space: O(n)# Handles n ≤ 10^5 efficiently*
```

```python
    n = len(nums)
    dp = [1] * n
    parent = [-1] * n  *# Track predecessors*
    
    for i in range(1, n):
        for j in range(i):
            if nums[j] < nums[i] and dp[j] + 1 > dp[i]:
                dp[i] = dp[j] + 1
                parent[i] = j
    
    *# Find index with maximum LIS length*
    max_length = max(dp)
    max_index = dp.index(max_length)
    
    *# Reconstruct LIS using parent pointers*
    lis = []
    current = max_index
    while current != -1:
        lis.append(nums[current])
        current = parent[current]
    
    return list(reversed(lis))
```

### Solução Detalhada: Problema 22 (Knapsack)

**Análise Matemática:**

```bash
State Space: dp[i][w] representa valor máximo usando items 0...i-1 com peso ≤ w
Base Case: dp[0][w] = 0 para todo w (sem items, valor = 0)
Transition: dp[i][w] = max(
    dp[i-1][w],                           # Não pegar item i-1
    dp[i-1][w-weight[i-1]] + value[i-1]   # Pegar item i-1 (se couber)
)
```

**Implementação Padrão:**

```python
def knapsack_2d(weights, values, capacity):
    """
    Standard 2D DP solution
    Time: O(n * W), Space: O(n * W)
    """
    n = len(weights)
    *# dp[i][w] = max value using first i items with weight limit w*
    dp = [[0] * (capacity + 1) for _ in range(n + 1)]
    
    for i in range(1, n + 1):
        for w in range(capacity + 1):
            *# Don't take item i-1*
            dp[i][w] = dp[i-1][w]
            
            *# Take item i-1 if it fits*
            if weights[i-1] <= w:
                dp[i][w] = max(dp[i][w], 
                              dp[i-1][w - weights[i-1]] + values[i-1])
    
    return dp[n][capacity]
```

**Otimização de Espaço:**

```python
def knapsack_optimized(weights, values, capacity):
    """
    Space-optimized version using 1D array
    Time: O(n * W), Space: O(W)
    
    Key insight: dp[i] only depends on dp[i-1], so we can use
    rolling array technique.
    """
    dp = [0] * (capacity + 1)
    
    for i in range(len(weights)):
        *# Iterate backwards to avoid using updated values*
        for w in range(capacity, weights[i] - 1, -1):
            dp[w] = max(dp[w], dp[w - weights[i]] + values[i])
    
    return dp[capacity]

*# Why backwards iteration?# If we go forwards, dp[w-weight[i]] might have been updated# in current iteration, leading to taking same item multiple times.*
```

**Reconstrução da Solução:**

```python
def knapsack_with_items(weights, values, capacity):
    """
    Return both maximum value and selected items
    """
    n = len(weights)
    dp = [[0] * (capacity + 1) for _ in range(n + 1)]
    
    *# Fill DP table*
    for i in range(1, n + 1):
        for w in range(capacity + 1):
            dp[i][w] = dp[i-1][w]
            if weights[i-1] <= w:
                dp[i][w] = max(dp[i][w], 
                              dp[i-1][w - weights[i-1]] + values[i-1])
    
    *# Reconstruct solution*
    selected_items = []
    i, w = n, capacity
    
    while i > 0 and w > 0:
        *# If value came from taking item i-1*
        if dp[i][w] != dp[i-1][w]:
            selected_items.append(i-1)  *# Item index*
            w -= weights[i-1]
        i -= 1
    
    return dp[n][capacity], list(reversed(selected_items))
```

### Solução Detalhada: Problema 26 (Maximum Flow)

**Algoritmo Ford-Fulkerson com DFS:**

```python
from collections import defaultdict, deque

class MaxFlow:
    def __init__(self, n):
        self.n = n
        *# Adjacency matrix for residual graph*
        self.capacity = [[0] * n for _ in range(n)]
        self.adj = [[] for _ in range(n)]
    
    def add_edge(self, u, v, cap):
        """Add edge with capacity from u to v"""
        self.capacity[u][v] += cap
        self.adj[u].append(v)
        self.adj[v].append(u)  *# Add reverse edge for residual graph*
    
    def bfs_find_path(self, source, sink, parent):
        """
        BFS to find augmenting path (Edmonds-Karp)
        Returns True if path exists, fills parent array
        """
        visited = [False] * self.n
        queue = deque([source])
        visited[source] = True
        
        while queue:
            u = queue.popleft()
            
            for v in self.adj[u]:
                if not visited[v] and self.capacity[u][v] > 0:
                    visited[v] = True
                    parent[v] = u
                    if v == sink:
                        return True
                    queue.append(v)
        
        return False
    
    def max_flow_edmonds_karp(self, source, sink):
        """
        Edmonds-Karp: Ford-Fulkerson with BFS
        Time: O(VE²), guaranteed polynomial time
        """
        parent = [-1] * self.n
        max_flow = 0
        
        while self.bfs_find_path(source, sink, parent):
            *# Find minimum capacity along the path*
            path_flow = float('inf')
            s = sink
            
            while s != source:
                path_flow = min(path_flow, self.capacity[parent[s]][s])
                s = parent[s]
            
            *# Update residual capacities*
            v = sink
            while v != source:
                u = parent[v]
                self.capacity[u][v] -= path_flow  *# Forward edge*
                self.capacity[v][u] += path_flow  *# Backward edge*
                v = parent[v]
            
            max_flow += path_flow
        
        return max_flow

*# Example usage:*
mf = MaxFlow(6)
mf.add_edge(0, 1, 16)  *# s -> v1: 16*
mf.add_edge(0, 2, 13)  *# s -> v2: 13*
mf.add_edge(1, 3, 12)  *# v1 -> v3: 12# ... add more edges*
result = mf.max_flow_edmonds_karp(0, 5)  *# source=0, sink=5*
```

**Análise de Complexidade**

- **Ford-Fulkerson (DFS)**: O(E × *max_flow*) — pode ser exponencial
- **Edmonds-Karp (BFS)**: O(VE²) — sempre polinomial
- **Dinic**: O(V²E) — melhor para grafos densos
- **Push-Relabel**: O(V³) — bom para implementação paralela

- *Problemas de emparelhamento (Matching problems*): Emparelhamento máximo em grafos bipartidos
- *Segmentação de imagens (Image segmentation*)*: Algoritmo de corte mínimo (min-cut*) para delimitação de regiões
