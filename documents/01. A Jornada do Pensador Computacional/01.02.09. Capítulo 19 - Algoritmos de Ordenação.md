## 19.1 Algoritmos Simples

### 19.1.1 Bubble Sort

- Percorre o vetor repetidamente, comparando pares adjacentes.
- Troca elementos fora de ordem "fazendo-os borbulhar" até o final.
- Complexidade: $O(n^2)$.
- Fácil de implementar, porém ineficiente para grandes listas.

Exemplo Python:

```python
def bubble_sort(lista):
    n = len(lista)
    for i in range(n-1):
        for j in range(n-1-i):
            if lista[j] > lista[j+1]:
                lista[j], lista[j+1] = lista[j+1], lista[j]
    return lista

*# Exemplo de uso*
lista = [4, 2, 7, 1, 5]
print(bubble_sort(lista))  *# Saída: [1, 2, 4, 5, 7]*
```

### 19.1.2 Selection Sort

- Seleciona o menor elemento do vetor e o coloca na posição correta.
- Repete o processo para as posições seguintes.
- Complexidade: $O(n^2)$, porém menos trocas que o Bubble Sort.

Exemplo Python:

```python
def selection_sort(lista):
    n = len(lista)
    for i in range(n):
        min_idx = i
        for j in range(i+1, n):
            if lista[j] < lista[min_idx]:
                min_idx = j
        lista[i], lista[min_idx] = lista[min_idx], lista[i]
    return lista

*# Exemplo de uso*
lista = [4, 2, 7, 1, 5]
print(selection_sort(lista))  *# Saída: [1, 2, 4, 5, 7]*
```

## 19.1.3 Insertion Sort

- Constrói a lista ordenada inserindo cada elemento na posição correta.
- Eficiente para listas pequenas e quase ordenadas.
- Complexidade: $O(n^2)$, melhor caso $O(n)$.

Exemplo Python:

```python
def insertion_sort(lista):
    for i in range(1, len(lista)):
        chave = lista[i]
        j = i - 1
        while j >= 0 and lista[j] > chave:
            lista[j+1] = lista[j]
            j -= 1
        lista[j+1] = chave
    return lista

*# Exemplo de uso*
lista = [4, 2, 7, 1, 5]
print(insertion_sort(lista))  *# Saída: [1, 2, 4, 5, 7]*
```

## 19.2 Algoritmos Avançados

### 19.2.1 Merge Sort

- Algoritmo divide e conquista.
- Divide a lista em partes, ordena recursivamente e mescla.
- Complexidade garantida: $O(n \log n)$.
- Usa espaço extra para mesclagem.

Exemplo Python:

```python
def merge_sort(lista):
    if len(lista) <= 1:
        return lista
    meio = len(lista) // 2
    esquerda = merge_sort(lista[:meio])
    direita = merge_sort(lista[meio:])
    return merge(esquerda, direita)

def merge(esquerda, direita):
    resultado = []
    i = j = 0
    while i < len(esquerda) and j < len(direita):
        if esquerda[i] < direita[j]:
            resultado.append(esquerda[i])
            i += 1
        else:
            resultado.append(direita[j])
            j += 1
    resultado.extend(esquerda[i:])
    resultado.extend(direita[j:])
    return resultado

*# Exemplo de uso*
lista = [4, 2, 7, 1, 5]
print(merge_sort(lista))  *# Saída: [1, 2, 4, 5, 7]*
```

### 19.2.2 Quick Sort

- Escolhe um pivô e particiona os elementos.
- Ordena recursivamente as partições.
- Complexidade média $O(n \log n)$, pior caso $O(n^2)$.
- Geralmente muito rápido na prática.

Exemplo Python:

```python
def quick_sort(lista):
    if len(lista) <= 1:
        return lista
    pivo = lista[len(lista) // 2]
    menores = [x for x in lista if x < pivo]
    iguais = [x for x in lista if x == pivo]
    maiores = [x for x in lista if x > pivo]
    return quick_sort(menores) + iguais + quick_sort(maiores)

*# Exemplo de uso*
lista = [4, 2, 7, 1, 5]
print(quick_sort(lista))  *# Saída: [1, 2, 4, 5, 7]*
```

## 19.2.3 Heap Sort

- Usa uma estrutura heap para ordenar.
- Complexidade $O(n \log n)$.
- Ordenação in-place, estável para muitos casos.

Exemplo Python:

```python
def heapify(lista, n, i):
    maior = i
    l = 2 * i + 1
    r = 2 * i + 2
    if l < n and lista[l] > lista[maior]:
        maior = l
    if r < n and lista[r] > lista[maior]:
        maior = r
    if maior != i:
        lista[i], lista[maior] = lista[maior], lista[i]
        heapify(lista, n, maior)

def heap_sort(lista):
    n = len(lista)
    for i in range(n//2 -1, -1, -1):
        heapify(lista, n, i)
    for i in range(n-1, 0, -1):
        lista[i], lista[0] = lista[0], lista[i]
        heapify(lista, i, 0)
    return lista

*# Exemplo de uso*
lista = [4, 2, 7, 1, 5]
print(heap_sort(lista))  *# Saída: [1, 2, 4, 5, 7]*
```

## 19.3 Algoritmos Especializados

---

### 19.3.1 Counting Sort

- Algoritmo não comparativo que conta o número de ocorrências de cada valor.
- Adequado para inteiros em intervalo conhecido e limitado.
- Complexidade: $O(n + k)$, onde $k$ é o intervalo dos valores.
- Estável e eficiente para dados numéricos discretos.

---

### 19.3.2 Radix Sort

- Ordena números processando dígito a dígito, do menos significativo para o mais significativo.
- Usa Counting Sort como sub-rotina para cada dígito.
- Complexidade: $O(d (n + k))$, onde $d$ é a quantidade de dígitos.
- Estável, ideal para números grandes com muitos dígitos.

---

### 19.3.3 Bucket Sort

- Divide os elementos em vários baldes (buckets), cada um contendo uma faixa do domínio.
- Ordena cada bucket individualmente (usando normalmente Insertion Sort).
- Depois concatena os buckets ordenados.
- Bom desempenho para dados uniformemente distribuídos.
- Complexidade esperada: $O(n + k)$, dependendo da distribuição.

---

## 19.4 Análise Comparativa

---

### 19.4.1 Complexidade Temporal

| Algoritmo | Complexidade Média | Observações |
| --- | --- | --- |
| Counting Sort | $O(n + k)$ | $k$ = faixa dos dados |
| Radix Sort | $O(d (n + k))$ | $d$ = número de dígitos |
| Bucket Sort | $O(n + k)$ | Depende de distribuição |

---

### 19.4.2 Complexidade Espacial

- Counting Sort e Radix Sort usam espaço adicional para contagem e buckets.
- Bucket Sort pode usar memória extra considerável dependendo do número de buckets.

---

### 19.4.3 Estabilidade

- Todos são **estáveis** se a ordenação interna dos buckets ou Counting Sort for estável.
- Estabilidade importante para algoritmos que dependem da ordem relativa de elementos iguais.

---

### 19.4.4 Casos de Uso

- **Counting Sort:** útil quando os dados são inteiros pequenos ou têm uma faixa limitada.
- **Radix Sort:** útil em strings, números grandes, onde comparações diretas são custosas.
- **Bucket Sort:** ideal para dados uniformemente distribuídos, como números reais em um intervalo.
