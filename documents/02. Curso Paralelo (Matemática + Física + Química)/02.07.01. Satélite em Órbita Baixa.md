## 🎯 **Objetivo:**

Calcular velocidade e período orbital e simular movimento.

**Passo a passo:**

1. Fórmula velocidade orbital:
    
    $v = \sqrt{\frac{GM}{R}}$
    
    Onde:
    
     $G = 6,674\times10^{-11}\ \mathrm{m^3/kg\,s^2}$,
    
     $M = 5,972\times10^{24}\ \mathrm{kg} (Terra)$,
    
    $R = R_T + h$.
    
2. Período orbital:
    
    $T = 2\pi \sqrt{\frac{R^3}{GM}}$
    
3. Simulação em Python:

```python
import numpy as np
import matplotlib.pyplot as plt

# dados
G = 6.674e-11
M = 5.972e24
R = 6371000 + 400000  # LEO
v = np.sqrt(G*M/R)
T = 2*np.pi*np.sqrt(R**3/(G*M))

# tempo
t = np.linspace(0, T, 1000)
x = R * np.cos(2*np.pi*t/T)
y = R * np.sin(2*np.pi*t/T)

plt.plot(0,0,'yo',markersize=12,label='Terra')
plt.plot(x, y, label='Órbita')
plt.axis('equal')
plt.legend()
plt.show()
```
