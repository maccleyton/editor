## 21.1 Conceitos Fundamentais

---

### 21.1.1 Subproblemas Sobrepostos

- Muitos problemas complexos podem ser divididos em subproblemas menores que se repetem várias vezes.
- Ao resolver recursivamente sem otimização, esses subproblemas são recalculados diversas vezes.
- A programação dinâmica evita esse custo armazenando os resultados das subinstâncias para reutilização.

---

### 21.1.2 Subestrutura Ótima

- Um problema apresenta subestrutura ótima se a solução ótima do problema contém soluções ótimas para os subproblemas.
- Isso garante que soluções parciais otimizadas leadem à solução global ótima.

---

### 21.1.3 Memoização vs Tabulação

- **Memoização (top-down):** abordagem recursiva que armazena resultados já calculados para evitar recomputação.
- **Tabulação (bottom-up):** resolve todos subproblemas pequenos primeiro e usa seus resultados para problemas maiores iterativamente.

---

### Exemplo prático simples: Fibonacci por Programação Dinâmica

```python
def fibonacci_memo(n, memo={}):
    if n in memo:
        return memo[n]
    if n <= 1:
        return n
    memo[n] = fibonacci_memo(n-1, memo) + fibonacci_memo(n-2, memo)
    return memo[n]

print(fibonacci_memo(10))  *# Saída: 55*

def fibonacci_tab(n):
    if n <= 1:
        return n
    fib = [0, 1]
    for i in range(2, n+1):
        fib.append(fib[i-1] + fib[i-2])
    return fib[n]

print(fibonacci_tab(10))  *# Saída: 55*
```

### 21.2.2 Problema da Mochila (Knapsack)

- Dado um conjunto de itens com peso e valor, determina quais itens incluir em uma mochila de capacidade limitada para maximizar o valor total.
- Duas versões comuns: 0/1 (cada item pode ser escolhido ou não) e fracionária.
- A versão 0/1 pode ser resolvida por PD com complexidade $O(n \times W)$, onde $n$ é número de itens e $W$ a capacidade da mochila.

Exemplo Python 0/1:

```python
def knapsack(valores, pesos, capacidade):
    n = len(valores)
    tabela = [[0]*(capacidade+1) for _ in range(n+1)]

    for i in range(1, n+1):
        for w in range(capacidade+1):
            if pesos[i-1] <= w:
                tabela[i][w] = max(valores[i-1] + tabela[i-1][w-pesos[i-1]], tabela[i-1][w])
            else:
                tabela[i][w] = tabela[i-1][w]
    return tabela[n][capacidade]

valores = [60, 100, 120]
pesos = [10, 20, 30]
capacidade = 50
print(knapsack(valores, pesos, capacidade))  *# Saída: 220*
```

### 21.2.3 Longest Common Subsequence (LCS)

- Encontra a maior subsequência comum entre duas sequências.
- Usado em comparação de versões de arquivos, bioinformática.
- Solução PD com tabela $m \times n$ baseada em recorrência:
    
    $L[i][j] = \begin{cases}
      0 & \text{se } i=0 \text{ ou } j=0 \\
      L[i-1][j-1] + 1 & \text{se } s[i-1] = t[j-1] \\
      \max(L[i-1][j], L[i][j-1]) & \text{caso contrário}
    \end{cases}$
    

Exemplo Python:

```python
def lcs(s, t):
    m, n = len(s), len(t)
    L = [[0]*(n+1) for _ in range(m+1)]

    for i in range(1, m+1):
        for j in range(1, n+1):
            if s[i-1] == t[j-1]:
                L[i][j] = L[i-1][j-1] + 1
            else:
                L[i][j] = max(L[i-1][j], L[i][j-1])
    return L[m][n]

s = "AGGTAB"
t = "GXTXAYB"
print(lcs(s, t))  *# Saída: 4*
```

### 21.2.4 Edit Distance (Distância de Edição)

- Mede o número mínimo de operações (inserção, remoção, substituição) para transformar uma string em outra.
- Utilizado em correção ortográfica, reconhecimento de fala.
- Solução PD similar a LCS, com tabela de custos.

Exemplo Python:

```python
def edit_distance(s1, s2):
    m, n = len(s1), len(s2)
    dp = [[0]*(n+1) for _ in range(m+1)]

    for i in range(m+1):
        dp[i][0] = i
    for j in range(n+1):
        dp[0][j] = j

    for i in range(1, m+1):
        for j in range(1, n+1):
            if s1[i-1] == s2[j-1]:
                dp[i][j] = dp[i-1][j-1]
            else:
                dp[i][j] = 1 + min(dp[i-1][j],     *# remoção*
                                   dp[i][j-1],     *# inserção*
                                   dp[i-1][j-1])   *# substituição*
    return dp[m][n]

print(edit_distance("kitten", "sitting"))  *# Saída: 3*
```

## 21.3 Estratégias de Implementação

---

### 21.3.1 Top-down (Memoização)

- Implementação recursiva que armazena os resultados dos subproblemas em uma estrutura de dados (geralmente um dicionário ou lista).
- Evita recomputações ao consultar o resultado já calculado antes de resolver o subproblema.
- Facilita escrita, mais intuitivo; pode consumir mais pilha e memória em alguns casos.

Exemplo Fibonacci com memoização:

```python
def fibonacci_top_down(n, memo={}):
    if n in memo:
        return memo[n]
    if n <= 1:
        return n
    memo[n] = fibonacci_top_down(n-1, memo) + fibonacci_top_down(n-2, memo)
    return memo[n]

print(fibonacci_top_down(10))  *# Saída: 55*
```

---

### 21.3.2 Bottom-up (Tabulação)

- Abordagem iterativa que resolve todos os subproblemas pequenos em ordem crescente.
- Usa uma tabela para guardar os resultados, evitando recursão.
- Geralmente mais eficiente em uso de memória e tempo em linguagens sem optimizações de recursão.

Exemplo Fibonacci com tabulação:

```python
def fibonacci_bottom_up(n):
    if n <= 1:
        return n
    dp = [0, 1]
    for i in range(2, n+1):
        dp.append(dp[i-1] + dp[i-2])
    return dp[n]

print(fibonacci_bottom_up(10))  *# Saída: 55*
```

---

### 21.3.3 Otimização de Espaço

- Muitas vezes nem todos os subproblemas precisam ser armazenados.
- Quando o estado depende somente dos últimos poucos valores, é possível reduzir o espaço usado.
- Exemplo otimização para Fibonacci:

```python
def fibonacci_optimized(n):
    if n <= 1:
        return n
    a, b = 0, 1
    for _ in range(2, n+1):
        a, b = b, a + b
    return b

print(fibonacci_optimized(10))  *# Saída: 55*
```
