# 🌊 Projeto 5 — Motor de Submarino (Termodinâmica + Eletrônica)

---

## 🎯 **Objetivo:**

Analisar duração do motor e eficiência.

- Energia disponível: $E = 5$ kWh → $5000$ Wh
- Potência do motor: $P = 500$ W → 0,5 kW
- Tempo de operação: $t = E/P = 10$ h

**Extra:** perda de energia por calor:

$\eta = \frac{P_\text{mec}}{P_\text{bateria}}$

Se $\eta = 0,8$, tempo útil = 10 h * 0,8 = 8 h.

---

Vamos montar um **simulador de bateria e motor submerso em Python**. Ele vai calcular:

- Descarga da bateria ao longo do tempo
- Consumo do motor
- Perdas por eficiência (calor)
- Gráfico de tensão, corrente e energia restante

---

### Código Python — Simulador de Motor Submarino

```python
import numpy as np
import matplotlib.pyplot as plt

# Parâmetros da bateria
E_total_kWh = 5           # energia total da bateria em kWh
V_nominal = 24            # tensão nominal da bateria em volts
P_motor_W = 500           # potência do motor em watts
eta = 0.8                 # eficiência do motor (80%)

# Conversão para energia em Wh
E_total_Wh = E_total_kWh * 1000

# Intervalo de tempo (1 minuto)
dt = 60                   # segundos
t_max = int(E_total_Wh / (P_motor_W*eta) * 3600)  # segundos necessários
steps = t_max // dt

# Inicialização de arrays
t_array = np.arange(0, steps*dt, dt)/3600  # tempo em horas
E_remanente = np.zeros(steps)
I_motor = np.zeros(steps)

E = E_total_Wh  # energia inicial em Wh

for i in range(steps):
    # Energia consumida no passo dt
    E_consumida_Wh = (P_motor_W / 1000) * dt / 3600 / eta * 1000  # Wh
    E -= E_consumida_Wh
    if E < 0:
        E = 0
    E_remanente[i] = E
    I_motor[i] = (P_motor_W / V_nominal) / eta  # corrente considerando eficiência

# Plotando resultados
plt.figure(figsize=(10,6))
plt.plot(t_array, E_remanente, label='Energia restante (Wh)')
plt.plot(t_array, I_motor, label='Corrente do motor (A)')
plt.xlabel('Tempo (h)')
plt.ylabel('Energia / Corrente')
plt.title('Simulação de bateria e motor submerso')
plt.legend()
plt.grid(True)
plt.show()
```

---

### Como funciona

1. O loop calcula a **energia consumida a cada minuto** pelo motor, considerando a **eficiência** (parte da energia vai para calor).
2. Calcula a **corrente instantânea** no motor: I=PV⋅ηI = \frac{P}{V \cdot \eta}.
3. Plota **energia restante** e **corrente ao longo do tempo**.
4. Dá pra alterar:
    - `E_total_kWh` → capacidade da bateria
    - `P_motor_W` → potência do motor
    - `eta` → eficiência real do sistema
