## 6.1 O que é um Algoritmo?

- Um **algoritmo** é um conjunto finito e ordenado de instruções bem definidas, que, a partir de entradas específicas, produzem uma saída desejada, solucionando um problema.
- É a base da programação e da solução de problemas computacionais.

Exemplo simples de algoritmo clássico (receita para fazer um café):

1. Ferva a água.
2. Coloque o pó de café na cafeteira.
3. Despeje a água fervida na cafeteira.
4. Aguarde alguns minutos.
5. Sirva o café.

Em pseudocódigo:

```bash
INÍCIO
    ferver_agua()
    colocar_po_cafe()
    despejar_agua()
    aguardar_tempo()
    servir_cafe()
FIM
```

## 6.2 Características de um Bom Algoritmo

---

### 6.2.1 Finitude

- O algoritmo deve terminar após um número finito de etapas; não deve entrar em loop infinito.

Exemplo errado:

```bash
Para i de 1 até infinito:
    imprimir i
```

Este nunca termina.

---

### 6.2.2 Definitude

- Cada passo do algoritmo deve ser claro, preciso e inequívoco.

Exemplo ruim: "Mexa a mistura até sentir que está boa" — não é preciso.

Exemplo bom: "Mexa a mistura por exatamente 5 minutos".

---

### 6.2.3 Entrada e Saída

- Algoritmo deve receber dados de entrada e produzir uma saída.

Exemplo:

- Entrada: lista de números.
- Saída: soma dos números.

Em Python:

```python
def soma_lista(lista):
    return sum(lista)
```

---

### 6.2.4 Efetividade

- As operações básicas devem ser suficientemente simples para serem executadas em tempo finito.

Exemplo: calcular a soma de dois números inteiros é efetivo; tentar computar sequência infinita não seria.

---

### 6.2.5 Generalidade

- Deve poder resolver uma classe de problemas, e não apenas casos específicos.

Exemplo: algoritmo de ordenação deve ordenar qualquer lista de números, não apenas listas fixas.

## 6.3 Representação de Algoritmos

Representar algoritmos de forma clara é essencial para comunicação, análise e implementação.

---

### 6.3.1 Linguagem Natural

- Descrever o algoritmo com palavras comuns e frases simples.
- Fácil entendimento, mas pode ser impreciso e ambíguo.

Exemplo:

- "Leia dois números, some-os e mostre o resultado."

Limitações:

- Pode dar margem a interpretações diferentes.

---

### 6.3.2 Fluxogramas

- Representação gráfica usando símbolos e flechas.
- Cada símbolo representa um tipo de ação:
    - Retângulo: processo/instrução
    - Paralelogramo: entrada/saída
    - Losango: decisão/condição
    - Setas indicam fluxo de execução

Exemplo: algoritmo para somar dois números

[Início] → [Leia A, B] → [S ← A + B] → [Imprima S] → [Fim]

Visualizar ajuda a entender fluxo e facilitam a detecção de erros.

---

### 6.3.3 Pseudocódigo

- Linguagem intermediária, semelhante a uma linguagem de programação, mas sem rigor sintático.
- Facilita a tradução para código real, mantendo clareza humana.

Exemplo:

```bash
INÍCIO
    LER A, B
    SOMA ← A + B
    IMPRIMIR SOMA
FIM
```

---

### 6.3.4 Português Estruturado

- Variante de pseudocódigo usando palavras do português com estrutura formal clara.
- Mais detalhado que linguagem natural mas menos técnico que código.

Exemplo:

```bash
Início
    Leia o valor de A
    Leia o valor de B
    Calcule a soma de A e B e armazene em SOMA
    Escreva o valor de SOMA
Fim
```

## 6.4 Tipos de Algoritmos

Os algoritmos podem ser classificados conforme seu fluxo e estrutura de controle, fundamentais para entender e aplicar paradigmas de programação.

---

### 6.4.1 Algoritmos Sequenciais

- Executam instruções uma após a outra, na ordem em que são escritas.
- Não possuem desvios nem repetições.

Exemplo em pseudocódigo:

```bash
INÍCIO
    Ler A
    Ler B
    Soma ← A + B
    Imprimir Soma
FIM
```

Exemplo em Python:

```python
A = int(input("Digite A: "))
B = int(input("Digite B: "))
Soma = A + B
print("Soma:", Soma)
```

---

### 6.4.2 Algoritmos Condicionais

- Incluem decisões baseadas em condições que alteram o fluxo.
- Usam estruturas como `if`, `else`.

Exemplo em pseudocódigo:

```bash
INÍCIO
    Ler N
    Se N > 0 então
        Imprimir "Número positivo"
    Senão
        Imprimir "Número não positivo"
    Fim Se
FIM
```

Exemplo em Python:

```python
N = int(input("Digite um número: "))
if N > 0:
    print("Número positivo")
else:
    print("Número não positivo")
```

---

### 6.4.3 Algoritmos Repetitivos

- Repetem um bloco de instruções enquanto uma condição for verdadeira.
- Estruturas comuns: `while`, `for`, `do-while`.

Exemplo pseudocódigo (contagem de 1 a 5):

```bash
INÍCIO
    i ← 1
    Enquanto i <= 5 faça
        Imprimir i
        i ← i + 1
    Fim Enquanto
FIM
```

Exemplo Python:

```python
i = 1
while i <= 5:
    print(i)
    i += 1
```

---

### 6.4.4 Algoritmos Recursivos

- Função/algoritmo que chama a si mesmo, reduzindo o problema a subproblemas menores.
- Deve ter condição de parada para evitar loops infinitos.

Exemplo pseudocódigo (fatorial):

```bash
Função fatorial(n)
    Se n = 0 então
        Retorna 1
    Senão
        Retorna n * fatorial(n - 1)
Fim Função
```

Exemplo Python:

```python
def fatorial(n):
    if n == 0:
        return 1
    else:
        return n * fatorial(n - 1)

print(fatorial(5))  *# 120*
```
