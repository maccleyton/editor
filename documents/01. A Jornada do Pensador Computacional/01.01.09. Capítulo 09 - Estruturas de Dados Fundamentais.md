## 9.1 Arrays (Vetores)

Arrays são estruturas de dados que armazenam coleções homogêneas em posições contíguas de memória, permitindo acesso rápido por índice.

---

### 9.1.1 Arrays Unidimensionais

- Lista linear de elementos do mesmo tipo, acessados por índice.

Exemplo em Python:

```python
numeros = [10, 20, 30, 40, 50]
print(numeros[2])  *# 30*
numeros[4] = 60    *# altera o último elemento*
print(numeros)     *# [10, 20, 30, 40, 60]*
```

---

### 9.1.2 Arrays Multidimensionais

- Arrays com múltiplas dimensões (ex: matrizes 2D).
- Em Python, podem ser representados por listas aninhadas ou, mais eficiente, pela biblioteca NumPy.

Exemplo com listas aninhadas:

```python
matriz = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]
print(matriz[1][2])  *# 6*
```

Exemplo com NumPy:

```python
import numpy as np

matriz_np = np.array([[1, 2, 3], [4, 5, 6]])
print(matriz_np[0, 1])  *# 2*
```

---

### 9.1.3 Operações Básicas

- Inserção, acesso, atualização e remoção de elementos.
- Percorrer arrays com loops.

Exemplo de acesso sequencial:

```python
for numero in numeros:
    print(numero)
```

---

### 9.1.4 Algoritmos de Busca Linear

- Percorre os elementos um a um até encontrar o alvo ou terminar a lista.

Pseudocódigo:

```bash
Para cada elemento em lista:
    Se elemento == busca então
        Retornar posição
Fim Para
Retornar -1  // Não encontrado
```

Python exemplo:

```python
def busca_linear(lista, alvo):
    for i, valor in enumerate(lista):
        if valor == alvo:
            return i
    return -1

pos = busca_linear(numeros, 40)  *# Retorna índice 3*
```

---

### 9.1.5 Algoritmos de Ordenação Simples

- Exemplos comuns: Bubble sort, Selection sort, Insertion sort.

Bubble sort (exemplo Python):

```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]

lista = [64, 34, 25, 12, 22]
bubble_sort(lista)
print(lista)  *# [12, 22, 25, 34, 64]*
```

## 9.2 Strings

---

### 9.2.1 Representação de Texto

- Strings são sequências ordenadas de caracteres usados para representar texto.
- Em Python, strings são imutáveis e podem ser definidas com aspas simples `'...'` ou duplas `"..."`.
- Índices começam em zero para acessar caracteres individualmente.

Exemplo:

```python
texto = "Olá Mundo"
print(texto[0])  *# 'O'*
print(len(texto))  *# 9*
```

---

### 9.2.2 Operações com Strings

- **Concatenação:** `+` une strings.
- **Repetição:**  repete uma string múltiplas vezes.
- **Fatiamento (slicing):** extrai substrings.
- **Pesquisa:** métodos como `.find()`, `.startswith()`, `.endswith()` para localizar substrings.
- **Transformação:** `.lower()`, `.upper()`, `.strip()` para manipular texto.

Exemplo:

```python
s1 = "Python"
s2 = " é legal"
print(s1 + s2)          *# Python é legal*
print(s1 * 3)           *# PythonPythonPython*
print(s1[1:4])          *# yth*
print("Python".upper()) *# PYTHON*
```

---

### 9.2.3 Pattern Matching

- Verifica se um padrão existe numa string.
- Pode usar operadores `in` ou funções específicas.

Exemplo:

```python
frase = "Aprenda Python"
print("Python" in frase)  *# True*
```

---

### 9.2.4 Expressões Regulares Básicas

- Ferramenta poderosa para buscar padrões complexos.
- Biblioteca `re` em Python.
- Exemplos básicos:

```python
import re

texto = "Meus números são 123-456 e 987-654."

*# Encontrar números com padrão ddd-ddd*
padrao = r"\d{3}-\d{3}"
resultados = re.findall(padrao, texto)

print(resultados)  *# ['123-456', '987-654']*
```

Alguns símbolos comuns:

- `\d` — dígito
- `.` — qualquer caractere
- **`*`** — zero ou mais
- `+` — um ou mais
- `?` — zero ou um
- `[abc]` — conjunto de caracteres a, b ou c
- `^` — começo da string
- `$` — fim da string

## 9.3 Listas

---

### 9.3.1 Listas Sequenciais

- Estrutura linear que armazena elementos sequencialmente.
- Em Python, representadas pelo tipo `list`, são mutáveis e ordenadas.
- Acesso por índice, podendo conter elementos heterogêneos.

Exemplo em Python:

```python
lista = ['Maçã', 'Banana', 'Laranja']
print(lista[1])  *# Banana*
lista.append('Melão')  
print(lista)  *# ['Maçã', 'Banana', 'Laranja', 'Melão']*
```

---

### 9.3.2 Listas Ligadas

- Estrutura onde cada elemento aponta para o próximo (nó com dado + ponteiro).
- Permite inserção e remoção eficientes em qualquer posição.
- Não é indexada, acesso sequencial é necessário.

Conceito básico (não nativo em Python, mas pode ser implementado):

```python
class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

class LinkedList:
    def __init__(self):
        self.head = None
```

---

### 9.3.3 Listas Duplamente Ligadas

- Cada nó possui referência para o nó anterior e o nó seguinte.
- Comporta navegação bidirecional.
- Mais flexível que lista ligada simples, mas consome mais memória.

Conceito básico:

```python
class Node:
    def __init__(self, data):
        self.data = data
        self.next = None
        self.prev = None
```

---

### 9.3.4 Listas Circulares

- Lista cujos elementos estão conectados formando um ciclo.
- O último nó aponta para o primeiro, possibilitando iteração contínua.

Uso comum para buffers circulares e sistemas de agendamento.

## 9.4 Pilhas (Stacks)

---

### 9.4.1 Conceito LIFO

- Pilha é uma estrutura de dados linear que segue o princípio **LIFO** (Last In, First Out), ou seja, o último elemento inserido é o primeiro a sair.
- Imagine uma pilha de livros: o último livro empilhado é o primeiro a ser retirado.

---

### 9.4.2 Operações Básicas

- **push:** adiciona um elemento no topo da pilha.
- **pop:** remove e retorna o elemento do topo da pilha.
- **top (ou peek):** acessa o elemento do topo sem removê-lo.
- **isEmpty:** verifica se a pilha está vazia.

---

### 9.4.3 Aplicações Práticas

- Gerenciamento da pilha de chamadas em linguagens e sistemas operacionais (funções recursivas).
- Avaliação e conversão de expressões matemáticas (notação pós-fixa).
- Histórico de navegação em navegadores (botão "voltar").
- Implementação de funcionalidade "Undo/Redo" em editores.
- Controle de navegação em jogos e simulações.

---

### 9.4.4 Implementação com Arrays e Listas

Em Python, a lista (`list`) pode ser usada para implementar pilhas.

Exemplo básico:

```python
pilha = []

*# push*
pilha.append(10)
pilha.append(20)
pilha.append(30)
print("Pilha após push:", pilha)  *# [10, 20, 30]# top*
topo = pilha[-1]
print("Topo da pilha:", topo)  *# 30# pop*
elemento = pilha.pop()
print("Elemento removido:", elemento)  *# 30*
print("Pilha após pop:", pilha)  *# [10, 20]# isEmpty*
print("Pilha vazia?", len(pilha) == 0)  *# False*
```

Exemplo como classe para encapsular comportamento:

```python
class Pilha:
    def __init__(self):
        self.itens = []

    def push(self, item):
        self.itens.append(item)

    def pop(self):
        if not self.is_empty():
            return self.itens.pop()
        else:
            raise IndexError("Pop de pilha vazia")

    def top(self):
        if not self.is_empty():
            return self.itens[-1]
        else:
            raise IndexError("Pilha vazia")

    def is_empty(self):
        return len(self.itens) == 0

pilha = Pilha()
pilha.push(10)
pilha.push(20)
print(pilha.top())  *# 20*
print(pilha.pop())  *# 20*
print(pilha.is_empty())  *# False*
```

## 9.5 Filas (Queues)

---

### 9.5.1 Conceito FIFO

- Filas são estruturas lineares que seguem o princípio **FIFO** (First In, First Out), ou seja, o primeiro elemento inserido é o primeiro a sair.
- Imagine uma fila em um caixa de supermercado: o primeiro cliente a chegar é o primeiro a ser atendido.

---

### 9.5.2 Operações Básicas

- **enqueue:** insere um elemento no final da fila.
- **dequeue:** remove e retorna o elemento do início da fila.
- **front (peek):** consulta o elemento da frente sem removê-lo.
- **isEmpty:** verifica se a fila está vazia.

Exemplo básico em Python usando lista:

```python
fila = []

*# enqueue*
fila.append(10)
fila.append(20)
fila.append(30)
print("Fila:", fila)  *# [10, 20, 30]# dequeue*
primeiro = fila.pop(0)
print("Removido:", primeiro)  *# 10*
print("Fila após dequeue:", fila)  *# [20, 30]# front*
print("Elemento da frente:", fila[0])  *# 20# isEmpty*
print("Fila vazia?", len(fila) == 0)  *# False*
```

---

### 9.5.3 Filas Circulares

- Filas circulares são filas de tamanho fixo onde o final se conecta ao início formando um ciclo.
- Evitam desperdício de espaço que ocorre nas filas tradicionais ao mover elementos.
- A posição de início e fim são controladas por índices que "dão a volta" no array.

Exemplo simples de fila circular (conceito):

```python
class FilaCircular:
    def __init__(self, tamanho):
        self.tamanho = tamanho
        self.fila = [None] * tamanho
        self.ini = 0
        self.fim = 0
        self.cont = 0

    def enqueue(self, valor):
        if self.cont == self.tamanho:
            print("Fila cheia!")
            return
        self.fila[self.fim] = valor
        self.fim = (self.fim + 1) % self.tamanho
        self.cont += 1

    def dequeue(self):
        if self.cont == 0:
            print("Fila vazia!")
            return None
        valor = self.fila[self.ini]
        self.ini = (self.ini + 1) % self.tamanho
        self.cont -= 1
        return valor
```

---

### 9.5.4 Filas de Prioridade

- Cada elemento da fila tem uma prioridade.
- Elementos com maior prioridade são removidos antes, independente da ordem de entrada.
- Usadas em sistemas operacionais, roteamento, e simulações.

Python possui `queue.PriorityQueue` para implementar.

Exemplo básico:

```python
import queue

pq = queue.PriorityQueue()
pq.put((2, "Tarefa média prioridade"))
pq.put((1, "Tarefa alta prioridade"))
pq.put((3, "Tarefa baixa prioridade"))

while not pq.empty():
    prioridade, tarefa = pq.get()
    print(tarefa)
```

Saída:

```bash
Tarefa alta prioridade
Tarefa média prioridade
Tarefa baixa prioridade
```
