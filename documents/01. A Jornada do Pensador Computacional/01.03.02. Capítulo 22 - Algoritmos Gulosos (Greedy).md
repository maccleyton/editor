## 22.1 Conceito de Algoritmo Guloso

- Algoritmo guloso constrói a solução por etapas, fazendo a **melhor escolha local** possível em cada etapa, na expectativa de que essa escolha leve à solução ótima global.
- Não reconsidera decisões tomadas, nem olha para consequências futuras.
- Normalmente são simples, rápidos e eficientes, mas nem sempre garantem uma solução ótima.
- Utilizados em diversos problemas combinatórios, onde soluções aproximadas ou ótimas são aceitáveis.

---

## 22.2 Propriedades Fundamentais

---

### 22.2.1 Escolha Gulosa

- Em cada passo, o algoritmo seleciona um candidato que frequentemente é o "mais apetitoso" ou "mais promissor" segundo algum critério pré-definido.
- A decisão é feita sem revisitar decisões anteriores.
- Provar que essa escolha local leva à solução global ótima é crucial para justificar o uso do algoritmo guloso.

---

### 22.2.2 Subestrutura Ótima

- Um problema possui subestrutura ótima se a solução ótima para o problema contém soluções ótimas para seus subproblemas.
- Isso permite que o algoritmo guloso construa a solução passo a passo sem comprometer a optimalidade.

---

### Exemplos de Algoritmos Gulosos

1. **Problema do Troco:** escolher moedas com valores maiores possíveis até que o valor total seja alcançado.
2. **Árvore Geradora Mínima:** algoritmos de Prim e Kruskal constroem a árvore com arestas de menor peso localmente.
3. **Atividades com Intervalos:** selecionar o maior número de atividades que não se sobrepõem, ordenando por fim.

## 22.3 Problemas Clássicos em Algoritmos Gulosos

---

### 22.3.1 Problema da Troca de Moedas (Coin Change)

- Objetivo: determinar o número mínimo de moedas necessárias para formar um valor.
- Algoritmo guloso escolhe sempre a maior moeda possível até completar o valor.
- Funciona para sistemas monetários com moedas “canais” (ex.: ).
- Caso contrário, pode não encontrar a solução ótima (exaustão exigida).

Exemplo Python (sistema canal):

```python
def troco_guloso(val, moedas):
    moedas.sort(reverse=True)
    contagem = 0
    for moeda in moedas:
        while val >= moeda:
            val -= moeda
            contagem += 1
    return contagem

moedas = [1, 5, 10, 25]
print(troco_guloso(63, moedas))  *# Saída: 6 (25+25+10+1+1+1)*
```

### 22.3.2 Problema do Caixeiro Viajante (TSP)

- Encontrar a rota mais curta que visite todos os vértices e retorne ao início.
- Problema NP-hard, sem algoritmo guloso garantido para ótima.
- Heurísticas gulosas (ex.: vizinho mais próximo) produzem soluções aproximadas rápidas.

---

### 22.3.3 Scheduling de Atividades (Activity Selection)

- Objetivo: agendar o máximo número de atividades não sobrepostas.
- Algoritmo guloso: escolher a atividade que termina primeiro e repetir para as restantes.
- Provado que essa escolha é ótima para problema de seleção de intervalos.

---

### 22.3.4 Algoritmos em Grafos (MST - Árvores Geradoras Mínimas)

- Algoritmos de Prim e Kruskal constroem árvores minimizando peso total.
- Escolhem localmente a aresta de menor peso que não forma ciclo.
- Fundamento para redes eficientes e estruturas de conexão.

---

### 22.4 Quando Usar Algoritmos Gulosos

- Quando o problema possui **subestrutura ótima** e **propriedade da escolha gulosa**.
- Quando é necessário algoritmo rápido para soluções aproximadas ou ótimas.
- Em problemas onde decisões locais não comprometem resultado global.
- Ideal para problemas com claro critério de seleção e decomposição.
