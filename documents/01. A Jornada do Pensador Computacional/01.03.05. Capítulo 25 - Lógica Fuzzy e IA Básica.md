## 25.1 Lógica Fuzzy

---

### 25.1.1 Conjuntos Fuzzy

- Extensão da teoria dos conjuntos clássicos onde a pertinência a um conjunto é gradual, com valores entre 0 e 1.
- Permite representar incerteza e vaguidade, modelando situações imprecisas como "quente", "alto", "um pouco".
- Formalmente, um conjunto fuzzy $A$ sobre o universo $U$ é definido por uma função de pertinência $\mu_A: U \to$.

---

### 25.1.2 Funções de Pertinência

- Determinam o grau em que um elemento pertence a um conjunto fuzzy.
- Formatos comuns: triangular, trapezoidal, gaussiana.
- Exemplo: função de pertinência para temperatura "quente" pode ser uma gaussiana centrada em um valor alto.

---

### 25.1.3 Operadores Fuzzy

- Extensões dos operadores lógicos clássicos para valores contínuos:
    - **AND (E):** geralmente $\min(\mu_A(x), \mu_B(x))$.
    - **OR (OU):** geralmente $\max(\mu_A(x), \mu_B(x))$.
    - **NOT (NÃO):** geralmente $1 - \mu_A(x)$.

---

### 25.1.4 Sistemas de Inferência

- Sistemas que aplicam regras fuzzy para tomar decisões ou inferir saídas a partir de entradas fuzzy.
- Passos principais:
    1. **Fuzzificação:** converter valores numéricos em graus de pertinência.
    2. **Aplicação das regras:** usar operadores fuzzy para combinar valores conforme regras “SE – ENTÃO”.
    3. **Agregação:** combinar todos os resultados das regras.
    4. **Defuzzificação:** converter resultado fuzzy em valor numérico preciso (ex.: método centróide).

---

### Exemplo Prático com Função de Pertinência Triangular (Python)

```python
def pertinencia_triang(x, a, b, c):
    if x <= a or x >= c:
        return 0
    elif a < x <= b:
        return (x - a) / (b - a)
    else:  *# b < x < c*
        return (c - x) / (c - b)

*# Teste da função*
x_valores = [10, 15, 20, 25, 30]
for x in x_valores:
    grau = pertinencia_triang(x, 15, 20, 25)
    print(f"x={x}, pertinência={grau}")
```

## 25.2 Algoritmos de Busca em IA

---

### 25.2.1 Busca em Profundidade Limitada

- Variante da busca em profundidade (DFS) que impõe um limite máximo na profundidade explorada.
- Evita exploração infinita em estados profundos ou ciclos longos.
- Útil para árvores ou grafos infinitos onde a profundidade da solução é limitada ou conhecida.
- Pode falhar se a profundidade limite for muito baixa, gerando resultados incompletos.

---

### Funcionamento Simplificado

- Executa DFS, mas quando atinge o limite lll, não expande mais aquele nó, fazendo backtrack.
- Exploração é semelhante à DFS tradicional, porém com profundidade máxima.

---

### Exemplo Python

```python
def dfs_limitada(grafo, inicio, objetivo, limite_profundidade):
    def dfs(no, profundidade):
        if profundidade > limite_profundidade:
            return False
        if no == objetivo:
            return True
        for vizinho in grafo.get(no, []):
            if dfs(vizinho, profundidade + 1):
                return True
        return False
    return dfs(inicio, 0)

grafo = {
    'A': ['B', 'C'],
    'B': ['D', 'E'],
    'C': ['F'],
    'D': [],
    'E': ['F'],
    'F': []
}

print(dfs_limitada(grafo, 'A', 'F', 2))  *# Saída: True*
print(dfs_limitada(grafo, 'A', 'F', 1))  *# Saída: False*
```

### 25.2.2 Busca A*

- Algoritmo de busca heurística otimizada que busca o caminho mais curto.
- Combina custo acumulado até o nó atual $g(n)$ com estimativa heurística ao objetivo $h(n)$.
- Usa função $f(n) = g(n) + h(n)$ para escolher o próximo nó a expandir.
- Completo e ótimo se a heurística for admissível (nunca superestima custo).

---

### Funcionamento Simplificado

- Inicializa uma fila de prioridade com o nó inicial.
- A cada passo, expande o nó com menor $f$.
- Atualiza custos de nós vizinhos e caminho até eles.
- Para quando o objetivo é extraído da fila.

---

### Exemplo Python Simplificado

```python
import heapq

def a_star(grafo, inicio, objetivo, heuristica):
    fila = []
    heapq.heappush(fila, (0 + heuristica[inicio], 0, inicio, [inicio]))
    visitados = set()

    while fila:
        f, custo, no, path = heapq.heappop(fila)
        if no == objetivo:
            return path
        if no in visitados:
            continue
        visitados.add(no)
        for vizinho, peso in grafo.get(no, []):
            if vizinho not in visitados:
                novo_custo = custo + peso
                heapq.heappush(fila, (novo_custo + heuristica[vizinho], novo_custo, vizinho, path + [vizinho]))
    return None

grafo = {
    'A': [('B',1), ('C',4)],
    'B': [('D',2), ('E',5)],
    'C': [('F',1)],
    'D': [],
    'E': [('F',1)],
    'F': []
}

heuristica = {'A': 5, 'B': 4, 'C': 3, 'D': 2, 'E': 1, 'F': 0}
caminho = a_star(grafo, 'A', 'F', heuristica)
print(caminho)  *# Saída: ['A', 'C', 'F']*
```

### 25.2.3 Algoritmos Genéticos Básicos

- Inspirados em seleção natural; resolvem problemas via evolução de populações.
- População inicial gera soluções candidatas, que passam por seleção, cruzamento (crossover) e mutação.
- Iteram até encontrar solução satisfatória.

---

### Estrutura Simplificada

- Representação do indivíduo (cromossomo).
- Função de avaliação (fitness).
- Operadores genéticos: seleção por mérito, cruzamento, mutação.

---

### Exemplo simples em Python

```python
import random

def gerar_individuo(tamanho):
    return [random.choice([0,1]) for _ in range(tamanho)]

def fitness(individuo):
    return sum(individuo)  *# Exemplo: maximizar número de 1s*

def mutacao(individuo, taxa):
    return [bit if random.random() > taxa else 1-bit for bit in individuo]

def crossover(pai1, pai2):
    ponto = random.randint(1, len(pai1)-1)
    return pai1[:ponto] + pai2[ponto:]

populacao = [gerar_individuo(10) for _ in range(5)]
for _ in range(10):  *# 10 gerações*
    populacao = sorted(populacao, key=fitness, reverse=True)
    nova_populacao = populacao[:2]
    while len(nova_populacao) < len(populacao):
        pai1, pai2 = random.sample(populacao[:3], 2)
        filho = crossover(pai1, pai2)
        filho = mutacao(filho, 0.1)
        nova_populacao.append(filho)
    populacao = nova_populacao
print(populacao[0], fitness(populacao[0]))
```
