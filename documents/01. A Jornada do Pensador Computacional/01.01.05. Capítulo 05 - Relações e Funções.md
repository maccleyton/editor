## 5.1 Relações

---

### 5.1.1 Pares Ordenados

- Um **par ordenado** é um conjunto de dois elementos na ordem $(a, b)$, onde a ordem importa.
- Exemplo: $(2, 3) \neq (3, 2)$.

Em Python:

```python
par1 = (2, 3)
par2 = (3, 2)
print(par1 == par2)  *# False*
```

---

### 5.1.2 Produto Cartesiano

- Produto cartesiano $A \times B$ é o conjunto de todos os pares ordenados $(a, b)$ com $a \in A$ e $b \in B$.

Exemplo:

- $A = \{1,2\}$, $B = \{x,y\}$
- $A \times B = \{(1,x),(1,y),(2,x),(2,y)\}$

Em Python:

```python
A = {1, 2}
B = {'x', 'y'}
produto = {(a, b) for a in A for b in B}
print(produto)  *# {(1, 'x'), (1, 'y'), (2, 'x'), (2, 'y')}*
```

---

### 5.1.3 Domínio e Contradomínio

- Para uma relação $R \subseteq A \times B$:
    - **Domínio** é o conjunto dos primeiros elementos dos pares (valores em A que se relacionam).
    - **Contradomínio** é o conjunto B ao qual o segundo elemento pertence.

Exemplo:

- $R = \{(1, x), (2, y)\}$
- Domínio: $\{1, 2\}$
- Contradomínio: $\{x, y\}$

Em Python para extrair domínio:

```python
R = {(1, 'x'), (2, 'y')}
dominio = {a for (a, b) in R}
print(dominio)  *# {1, 2}*
```

---

### 5.1.4 Propriedades das Relações

- **Reflexiva:** $\forall a \in A, (a,a) \in R$
    
    Exemplo: relação "igual a" em números.
    
- **Simétrica:** $\forall a,b \in A, (a,b) \in R \Rightarrow (b,a) \in R$
    
    Exemplo: relação "é amigo de".
    
- **Transitiva:** $\forall a,b,c \in A, (a,b) \in R \land (b,c) \in R \Rightarrow (a,c) \in R$
    
    Exemplo: relação de "é antecessor" em genealogia.

## 5.2 Funções Matemáticas

Funções estabelecem relações específicas entre elementos de conjuntos, chave para modelagem, computação e algoritmos.

---

### 5.2.1 Definição Formal

- Uma **função** $f$ de um conjunto $A$ para $B$ é uma relação que associa a cada elemento $a \in A$ exatamente um elemento $b \in B$.
- Notação: $f : A \rightarrow B$, com $f(a) = b$.

Exemplo informal:

- $f(x) = x^2$, de $\mathbb{R}$ em $\mathbb{R}$.

Em Python:

```python
def f(x):
    return x ** 2
```

---

### 5.2.2 Tipos de Funções

- **Injetora (injeção):** cada elemento do contradomínio tem **no máximo um** correspondente no domínio. $f(a) = f(b) \Rightarrow a = b$.
- **Sobrejetora (sobrescrição):** cada elemento do contradomínio tem **pelo menos um** correspondente no domínio. A função cobre todo o conjunto $B$.
- **Bijetora:** é injetora *e* sobrejetora; mapeamento um a um que cobre todo $B$.

Exemplos:

- Função $f(x) = 2x + 3$ em $\mathbb{R}$ é bijetora.

---

### 5.2.3 Função Inversa

- Dada uma função bijetora $f: A \rightarrow B$, sua inversa $f^{-1}$ é a função que para cada $b \in B$ retorna $a \in A$ tal que $f(a) = b$.

Exemplo:

- Se $f(x) = 2x + 3$, a inversa é $f^{-1}(y) = (y - 3)/2$.

Em Python:

```python
def f(x):
    return 2 * x + 3

def f_inv(y):
    return (y - 3) / 2
```

---

### 5.2.4 Composição de Funções

- A composição $g \circ f$ é a aplicação de duas funções em sequência: $(g \circ f)(x) = g(f(x))$.

Exemplo:

- $f(x) = x + 1$
- $g(x) = 2x$
- $(g \circ f)(x) = 2(x + 1) = 2x + 2$

Em Python:

```python
def f(x):
    return x + 1

def g(x):
    return 2 * x

def g_of_f(x):
    return g(f(x))
```

### Exercícios Comentados

1. Prove se $f(x) = x^2$, para $x \in \mathbb{R}$ é injetora, sobrejetora ou bijetora.
    
    Resposta: Não é injetora nem bijetora no domínio real porque $f(-1) = f(1)$, nem cobre todos os reais negativos (não é sobrejetora).
    
2. Encontre a inversa da função $f(x) = 3x - 4$.
    
    Resposta: $f^{-1}(y) = (y + 4)/3$.
    
3. Calcule $(g \circ f)(2)$ para $f(x) = x^2$, $g(x) = x + 3$.
    
    Resposta: $g(f(2)) = g(4) = 7$.
    
4. Implemente em Python uma verificação simples de injeção usando uma lista de pares $(x, f(x))$.

## 5.3 Aplicações em Programação

Funções matemáticas modelam diversas estruturas e processos computacionais, proporcionando organização, eficiência e clareza.

---

### 5.3.1 Funções/Métodos

- Em programação, funções ou métodos são blocos reutilizáveis de código que recebem entradas (parâmetros) e retornam saídas.
- Encapsulam comportamento, facilitam a modularidade e manutenção.

Exemplo em Python:

```python
def soma(a, b):
    return a + b

resultado = soma(3, 5)
print(resultado)  *# 8*
```

---

### 5.3.2 Mapeamentos (Hash Tables, Dictionaries)

- Mapeamentos associam chaves a valores, representando funções no sentido matemático.
- Estruturas como *dictionaries* e *hash tables* implementam esse conceito para acesso rápido.

Python exemplo:

```python
dicionario = {'chave1': 10, 'chave2': 20}
print(dicionario['chave1'])  *# 10*
```

- Cada chave mapeia para um valor único, similar a uma função.

---

### 5.3.3 Transformações de Dados

- Funções transformam dados, como filtros, mapeamentos ou reduções.
- Muito usada em manipulação de listas, streams e pipelines de dados.

Exemplo:

```python
numeros = [1, 2, 3, 4]
quadrados = list(map(lambda x: x**2, numeros))
print(quadrados)  *# [1, 4, 9, 16]*
```

- Essa transformação aplica a função $f(x) = x^2$ a todos os elementos da lista.

---

### 5.3.4 APIs e Interfaces

- APIs expõem funções/métodos para interação entre softwares ou componentes.
- Interfaces definem contratos de métodos, abstraindo detalhes da implementação, similar à ideia de funções como mapeamentos.

Exemplo simplificado em Python:

```python
class Calculadora:
    def somar(self, a, b):
        return a + b

calc = Calculadora()
print(calc.somar(5, 7))  *# 12*
```

- Aqui, o método `somar` é uma função aplicada a entradas, retornando resultado.
