## 3.1 Predicados e Quantificadores

- **Predicado**: é uma função lógica que depende de uma ou mais variáveis. Por exemplo, "é par(x)" retorna True se x for par, False se não.
- **Quantificadores**: símbolos usados para generalizar proposições sobre conjuntos.

Exemplo matemático:

- Proposição: "4 é par" → proposição específica.
- Predicado: "x é par" → pode ser avaliado para diferentes valores de x.

---

## 3.2 Quantificador Universal (∀)

### Definição

- O quantificador universal $\forall$ significa "para todo", "para qualquer".
- Expressa que uma propriedade vale para todos os elementos de um conjunto.

Exemplo formal:

- $\forall x \in \mathbb{N}, \quad x + 0 = x$
    
    ("Para todo número natural, somar zero não altera o valor.")
    

Em programação:

```python
def todos_pares(lista):
    return all(x % 2 == 0 for x in lista)
```

Aqui, `all` aplica o predicado a todos os elementos, simulando o $\forall$.

---

## 3.3 Quantificador Existencial (∃)

### Definição

- O quantificador existencial $\exists$ significa "existe pelo menos um".

Exemplo formal:

- $\exists x \in \mathbb{N}, \quad x \text{ é ímpar}$
    
    ("Existe pelo menos um número ímpar.")
    

Em programação:

```python
def existe_par(lista):
    return any(x % 2 == 0 for x in lista)
```

Aqui, `any` representa o $\exists$.

---

## 3.4 Negação de Quantificadores

A negação troca o tipo do quantificador:

- $\neg(\forall x, P(x)) \equiv \exists x, \neg P(x)$
- $\neg(\exists x, P(x)) \equiv \forall x, \neg P(x)$

Exemplo formal:

- Negação de "todo aluno passou" → "existe pelo menos um aluno que não passou".

Em programação:

```python
def nem_todos_passaram(lista):
    return any(nota < 7 for nota in lista)
```

Simboliza a negação do universal ($\forall$), usando o existencial ($\exists$) sobre o predicado negado.

## 3.5 Predicados em Programação

### 3.5.1 Funções Booleanas

Funções que retornam apenas True ou False, baseadas em propriedades.

Exemplo:

```python
def eh_par(x):
    return x % 2 == 0
```

### 3.5.2 Validação de Dados

Uso de predicados para verificar propriedades e restrições de entrada.

Exemplo:

```python
def validar_usuario(usuario):
    return len(usuario) > 3 and usuario.isalnum()
```

### 3.5.3 Filtros e Condições

Aplicação de predicados para selecionar elementos em estruturas de dados.

Exemplo com filter:

```python
idades = [17, 18, 21, 15]
maiores = list(filter(lambda x: x >= 18, idades))
*# maiores = [18, 21]*
```

def eh_primo(x):

```python
def algum_nome_grande(nomes):

```

1. **Explique a diferença entre all e any no contexto dos predicados em programação.**

- `any` representa o existencial ($\exists$), basta um cumprir o predicado.
