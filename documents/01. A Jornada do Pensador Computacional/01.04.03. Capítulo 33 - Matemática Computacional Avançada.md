## 33.1 Análise Numérica

---

### 33.1.1 Erro de Arredondamento

- Erros introduzidos quando números reais são representados com precisão finita (ponto flutuante).
- Pequenos erros podem se acumular e afetar resultados, especialmente em cálculos iterativos.

---

### 33.1.2 Estabilidade Numérica

- Capacidade de um algoritmo de controlar e não amplificar erros.
- Algoritmos instáveis levam a resultados imprecisos ou divergentes.
- Escolher algoritmos estáveis é crucial para confiabilidade.

---

### 33.1.3 Métodos Iterativos

- Técnicas que geram sequências sucessivas aproximando a solução exata de um problema.
- Começam com um chute inicial e melhoram soluções até atingir critério de convergência.
- Comuns para resolver sistemas lineares, equações não lineares e otimização.

---

### Exemplo Passo a Passo: Método da Bissecção para encontrar raiz de $f(x) = x^3 - x - 2$

```python
def f(x):
    return x**3 - x - 2

def bisseccao(a, b, tol=1e-5):
    if f(a)*f(b) >= 0:
        return None  *# Intervalo inválido*
    c = a
    while (b - a) / 2 > tol:
        c = (a + b) / 2
        if f(c) == 0:
            return c
        elif f(a) * f(c) < 0:
            b = c
        else:
            a = c
    return c

raiz = bisseccao(1, 2)
print(f"Raiz aproximada: {raiz:.6f}")
```

### 33.2.1 Algoritmos Geométricos Básicos

- Algoritmos que tratam operações fundamentais em objetos geométricos como pontos, linhas, polígonos.
- Exemplos incluem cálculo de área, distância, interseção de segmentos, produtos vetoriais e orientação de pontos.
- Base para problemas mais complexos como envoltórias convexas e triangulação.

---

### Exemplo Guiado: Cálculo da Área de um Triângulo via Produto Vetorial

Dados três pontos A, B, C no plano, a área do triângulo pode ser calculada por:

$Área = \frac{1}{2} |(B - A) \times (C - A)|$

```python
def area_triangulo(A, B, C):
    return abs((B[0]-A[0])*(C[1]-A[1]) - (B[1]-A[1])*(C[0]-A[0]))/2

A = (0, 0)
B = (4, 0)
C = (0, 3)

print(f"Área do triângulo: {area_triangulo(A,B,C)}")  *# Saída: 6.0*
```

## 33.3 Processamento de Sinais

---

### 33.3.1 Transformada de Fourier Discreta (DFT)

- A DFT converte uma sequência finita de sinais no domínio do tempo em sua representação no domínio da frequência.
- Permite analisar componentes de frequência numa amostra de sinal digital.
- A DFT é definida para $N$ amostras $x_n$ como:

$X_k = \sum_{n=0}^{N-1} x_n \cdot e^{-i 2 \pi \frac{k n}{N}}, \quad k=0,1,...,N-1$

- FFT (Fast Fourier Transform) é algoritmo eficiente para calcular DFT.

---

### Exemplo Prático: Computar DFT simples com NumPy

```python
import numpy as np
import matplotlib.pyplot as plt

*# Sinal exemplo: soma de frequências 5Hz e 20Hz*
fs = 100  *# taxa de amostragem*
t = np.arange(0, 1, 1/fs)
sinal = 0.6 * np.sin(2 * np.pi * 5 * t) + 0.4 * np.sin(2 * np.pi * 20 * t)

*# DFT via FFT*
X = np.fft.fft(sinal)
freq = np.fft.fftfreq(len(X), 1/fs)

plt.plot(freq[:len(freq)//2], np.abs(X)[:len(X)//2])
plt.title("Espectro de Frequência")
plt.xlabel("Frequência (Hz)")
plt.ylabel("Magnitude")
plt.show()
```

## 33.4 Otimização Combinatória

---

### 33.4.1 Branch and Bound

- Técnica exata para resolver problemas de otimização combinatória.
- Explora espaço de soluções em árvore, cortando ("podando") ramos quando não podem conter solução melhor que a atual.
- Exemplo: aplicado para o problema do caixeiro viajante e programação inteira.

---

### 33.4.2 Programação Inteira

- Modelo matemático para otimização onde variáveis são restritas a valores inteiros.
- Utilizado para problemas de alocação, roteamento, escalonamento.
- Soluções podem ser encontradas com algoritmos exatos (branch and bound, branch and cut).

---

### 33.4.3 Metaheurísticas

- Algoritmos estocásticos que buscam boas soluções em espaços grandes e complexos.
- Exemplos: Algoritmos Genéticos, Simulated Annealing, Busca Tabu, Colônia de Formigas.
- Permitem escapar de ótimos locais usando mecanismos como mutação, resfriamento e memória.

---

### 33.4.4 Algoritmos de Aproximação

- Algoritmos que fornecem soluções próximas ao ótimo, com garantias teóricas de desempenho.
- Úteis para problemas NP-difíceis onde solução exata é impraticável.
- Exemplo: algoritmos de aproximação para o problema do conjunto dominante.

---

### Exemplo Prático: Algoritmo de Busca Branch and Bound para Problema da Mochila

```python
def mochila_branch_and_bound(pesos, valores, capacidade):
    n = len(pesos)
    max_valor = 0

    def backtrack(i, peso_atual, valor_atual):
        nonlocal max_valor
        if i == n:
            max_valor = max(max_valor, valor_atual)
            return
        if peso_atual + pesos[i] <= capacidade:
            backtrack(i+1, peso_atual + pesos[i], valor_atual + valores[i])
        backtrack(i+1, peso_atual, valor_atual)

    backtrack(0, 0, 0)
    return max_valor

pesos = [2, 3, 4, 5]
valores = [3, 4, 5, 6]
capacidade = 5
print(f"Valor máximo da mochila: {mochila_branch_and_bound(pesos, valores, capacidade)}")
```
