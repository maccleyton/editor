## 🎯 **Objetivo:**

Modelar decaimento exponencial.

**Equação:**

$N(t) = N_0 e^{-\lambda t},\quad T_{1/2} = \frac{\ln 2}{\lambda}$

**Exemplo:** 1000 núcleos, meia-vida 10 h, tempo 30 h.

- $\lambda = \ln2/10 \approx 0.0693\ \mathrm{h^{-1}}$
- $N(30) = 1000 e^{-0.0693*30} = 125$

**Simulação Python:**

```python
import numpy as np
import matplotlib.pyplot as plt

N0 = 1000
T_half = 10
lambda_ = np.log(2)/T_half
t = np.linspace(0,50,500)
N = N0 * np.exp(-lambda_ * t)

plt.plot(t, N)
plt.xlabel("Tempo (h)")
plt.ylabel("Número de núcleos")
plt.title("Decaimento Radioativo")
plt.show()
```
