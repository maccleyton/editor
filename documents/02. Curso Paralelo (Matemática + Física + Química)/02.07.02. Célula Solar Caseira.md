## 🎯 **Objetivo:**

Criar/simular célula solar DSSC.

**Passo a passo:**

1. Escolher pigmento natural (ex.: beterraba, mirtilo).
2. Preparar óxido de titânio em vidro condutor.
3. Aplicar pigmento, montar eletrodos.
4. Medir tensão/corrente com multímetro.
5. Conceito físico-químico:
    - Band gap do TiO₂ ≈ 3,2 eV → excita elétrons.
    - Energia química (elétrons excitados) → corrente elétrica.

**Extra:** simular com Python:

```python
import numpy as np
import matplotlib.pyplot as plt

I_sc = 0.003  # corrente de curta-circuito (A)
V_oc = 0.6    # tensão circuito aberto (V)

V = np.linspace(0, V_oc, 100)
I = I_sc * (1 - V/V_oc)  # aproximação linear

plt.plot(V, I)
plt.xlabel('Tensão (V)')
plt.ylabel('Corrente (A)')
plt.title('Curva I-V simplificada da célula solar')
plt.show()
```
