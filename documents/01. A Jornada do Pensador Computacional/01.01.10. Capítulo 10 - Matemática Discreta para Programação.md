## 10.1 Sistemas de Numeração

---

### 10.1.1 Sistema Decimal

- Sistema de base 10, com dígitos de 0 a 9.
- É o sistema numérico mais usado no dia a dia.

Exemplo: $429 = 4 \times 10^2 + 2 \times 10^1 + 9 \times 10^0$

---

### 10.1.2 Sistema Binário

- Sistema de base 2, utiliza apenas os dígitos 0 e 1.
- Fundamental para representação interna de dados e instruções em computadores.

Exemplo: $1011_2 = 1 \times 2^3 + 0 \times 2^2 + 1 \times 2^1 + 1 \times 2^0 = 11_{10}$

---

### 10.1.3 Sistema Octal

- Sistema de base 8, usa dígitos de 0 a 7.
- Facilitava escrita e leitura de binários agrupando bits em grupos de três.

Exemplo: $157_8 = 1 \times 8^2 + 5 \times 8^1 + 7 \times 8^0 = 111_{10}$

---

### 10.1.4 Sistema Hexadecimal

- Sistema de base 16, usa dígitos 0 a 9 e letras A a F (10 a 15).
- Muito usado em programação para representar bytes e endereços.

Exemplo:

$1A3_F = 1 \times 16^3 + 10 \times 16^2 + 3 \times 16^1 + 15 \times 16^0 = 6719_{10}$

---

### 10.1.5 Conversões entre Sistemas

- **Decimal para binário:** dividir sucessivamente por 2, registrar restos.
- **Binário para decimal:** somar os produtos dos bits pelos pesos 2i2^i2i.
- **Binário para octal/hexadecimal:** agrupar bits em blocos de 3 (octal) ou 4 (hex) e converter.
- **Octal/hexadecimal para binário:** substituir cada dígito pelo equivalente em 3 ou 4 bits.

---

### 10.1.6 Aritmética em Diferentes Bases

- Operações como soma, subtração, multiplicação, divisão são feitas conforme regras da base.
- Exemplo de soma binária:

$1011_2 + 1101_2 = (1+1)_{carry} + \ldots = 11000_2$

## 10.2 Representação de Números em Computadores

---

### 10.2.1 Complemento de Dois

- Método padrão para representar números inteiros com sinal em binário.
- Permite representar números positivos e negativos de forma uniforme.

**Como calcular:**

Para um número negativo:

1. Escreve-se o valor absoluto em binário.
2. Inverte-se todos os bits (conhecido como complemento de um).
3. Soma-se 1 ao resultado (obtendo o complemento de dois).

Exemplo com 4 bits, representando -5:

- Valor absoluto: 5 → 0101
- Inverter bits: 1010
- Somar 1: 1011

Representação binária de -5 é 1011.

**Vantagens:**

- Só há uma representação para zero.
- Soma e subtração funcionam com a mesma lógica da soma sem sinal.

---

### 10.2.2 Ponto Fixo vs Ponto Flutuante

- **Ponto fixo:**
    
    Representa números reais com um número fixo de dígitos após a vírgula decimal.
    
    Simples, eficiente para números com faixa limitada (ex: contabilidade).
    
- **Ponto flutuante:**
    
    Números reais representados permitindo posição variável da vírgula, usando notação científica em binário:
    
    $(-1)^S \times 1.M \times 2^{E}$
    
    onde $S$ é o bit de sinal, $M$ é a mantissa, e $E$ o expoente.
    

---

### 10.2.3 IEEE 754

- Padrão para representação de números em ponto flutuante em computadores.
- Define formatos de 32 bits (precisão simples) e 64 bits (precisão dupla).

Estrutura de 32 bits:

- 1 bit sinal
- 8 bits expoente
- 23 bits mantissa

Exemplo:

Número 6.5 em binário: 110.1

Convertido para forma normalizada e representado conforme especificação.

---

### 10.2.4 Overflow e Underflow

- **Overflow:** ocorre quando um cálculo produz resultado fora do limite máximo representável (ex.: somar dois números grandes demais).
    
    Pode causar erro ou valor incorreto.
    
- **Underflow:** ocorre quando um número é muito pequeno para ser representado com precisão, aproximado a zero.

Ambos são importantes para cuidados em cálculos numéricos e engenharia de software.

## 10.3 Operações Bit-wise

---

### 10.3.1 AND, OR, XOR, NOT

- **AND (&):** retorna 1 se ambos os bits forem 1, caso contrário 0.
    
    Exemplo: $5 \, (0101_2) \; \& \; 3 \, (0011_2) = 1 \, (0001_2)$
    
    Python:
    
    ```python
    a = 5  *# 0b0101*
    b = 3  *# 0b0011*
    print(a & b)  *# 1*
    ```
    
- **OR (|):** retorna 1 se pelo menos um bit for 1.
    
    Exemplo: $5 \, (0101_2) \; | \; 3 \, (0011_2) = 7 \, (0111_2)$
    
    Python:
    
    ```python
    print(a | b)  *# 7*
    ```
    
- **XOR (^):** retorna 1 se os bits forem diferentes.
    
    Exemplo: $5 \, (0101_2) \; \oplus \; 3 \, (0011_2) = 6 \, (0110_2)$
    
    Python:
    
    ```python
    print(a ^ b)  *# 6*
    ```
    
- **NOT (~):** inverte todos os bits (complemento de dois).
    
    Python:
    
    ```python
    print(~a)  *# -6 (em complemento de dois)*
    ```
    

---

### 10.3.2 Shift Left e Shift Right

- **Shift left (<<):** desloca bits para a esquerda, equivalente a multiplicar por 2n2^n2n.
    
    Exemplo:
    
    ```python
    print(a << 2)  *# 20, pois 5 * 2^2 = 20*
    ```
    
- **Shift right (>>):** desloca bits para a direita, equivalente a dividir por 2n2^n2n e truncar.
    
    Exemplo:
    
    ```python
    print(a >> 1)  *# 2, pois 5 // 2 = 2*
    ```
    

---

### 10.3.3 Máscaras de Bits

- Máscaras são valores usados para ativar, desativar ou verificar bits específicos.
- Permitem isolar, ligar ou desligar bits.

Exemplo para verificar se o bit 3 (da direita, índice 2) está ligado:

```python
valor = 13  *# 0b1101*
mascara = 0b0100  *# bit 3 ligado*
if valor & mascara:
    print("Bit 3 está ligado")
else:
    print("Bit 3 está desligado")
```
