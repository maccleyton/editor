## 8.1 Conceito de Variável

- Uma variável é um nome simbólico usado para armazenar um valor na memória do computador.
- Serve para referenciar dados que podem ser manipulados durante a execução do programa.
- Em linguagens como Python, a declaração da variável está associada à atribuição do valor, não sendo necessário declarar tipos explicitamente.

Exemplo Python:

```python
idade = 25
nome = "Ana"
altura = 1.75
ativo = True
print(idade, nome, altura, ativo)
```

---

## 8.2 Tipos Primitivos

---

### 8.2.1 Inteiros (int)

- Representam números inteiros, sem parte decimal.
- Exemplos: -10, 0, 42.

Em Python:

```python
num = 10
print(type(num))  *# <class 'int'>*
```

---

### 8.2.2 Ponto Flutuante (float)

- Representam números reais, com parte decimal.
- Exemplos: 3.14, -2.5, 0.0.

Em Python:

```python
pi = 3.1415
print(type(pi))  *# <class 'float'>*
```

---

### 8.2.3 Caracteres (str)

- Sequência de caracteres usada para armazenar texto.
- Podem ser definidos com aspas simples ou duplas.

Exemplos:

```python
letra = 'a'
palavra = "Olá"
print(type(letra))    *# <class 'str'>*
print(type(palavra))  *# <class 'str'>*
```

---

### 8.2.4 Booleanos (bool)

- Representam valores lógicos: `True` (verdadeiro) ou `False` (falso).
- Utilizados em decisões, condições e controle de fluxo.

Exemplo:

```python
ativo = True
print(type(ativo))  *# <class 'bool'>*
```

## 8.3 Tipos Compostos

Tipos compostos armazenam coleções de elementos, podendo ser homogêneos ou heterogêneos, permitindo manipulação estruturada de dados em programas.

---

### 8.3.1 Strings

- Sequência ordenada de caracteres, usada para representar texto.
- Imutáveis na maioria das linguagens, incluindo Python.
- Criadas com aspas simples ('') ou duplas ("").

Exemplo Python:

```python
nome = "Ana"
frase = 'Olá, mundo!'
print(nome[0])  *# 'A'*
print(len(frase))  *# 10*
```

---

### 8.3.2 Arrays

- Estruturas de dados que armazenam coleções homogêneas (mesmo tipo).
- Permitem acesso por índice, iteração e manipulação eficiente.
- Em Python, listas (`list`) são usadas como arrays dinâmicos, mas o módulo `array` provê arrays com restrição de tipo.

Exemplo Python (lista como array):

```python
numeros = [10, 20, 30, 40]
print(numeros[2])  *# 30*
numeros.append(50)
print(numeros)  *# [10, 20, 30, 40, 50]*
```

---

### 8.3.3 Registros/Estruturas

- Coleções heterogêneas que agrupam diferentes tipos de dados relacionados.
- Em Python, dicionários (`dict`) ou `namedtuple` simulam registros.

Exemplo com dicionário:

```python
aluno = {
    "nome": "João",
    "idade": 20,
    "altura": 1.75,
    "ativo": True
}
print(aluno["nome"])  *# João*
```

Exemplo com `namedtuple`:

```python
from collections import namedtuple
Aluno = namedtuple("Aluno", ["nome", "idade", "altura"])
aluno1 = Aluno("Ana", 22, 1.68)
print(aluno1.nome)  *# Ana*
```

---

### 8.3.4 Uniões

- Em linguagens estáticas, uniões armazenam diferentes tipos em um mesmo espaço de memória, mas só um tipo válido por vez.
- Python não tem união nativa, mas pode-se usar tipos genéricos ou variáveis que assumem valores de qualquer tipo devido à tipagem dinâmica.

Uso prático em Python:

```python
valor = 10       *# inteiro*
valor = "dez"    *# string*
print(valor)     *# dez*
```

Em linguagens como C, uniões são definidas com `union`.

## 8.4 Escopo de Variáveis

---

### 8.4.1 Escopo Local

- Variáveis locais são declaradas dentro de funções ou blocos e só podem ser acessadas dentro desse contexto.
- São criadas ao entrar no bloco/função e destruídas ao sair.
- Variáveis locais isolam dados para evitar conflitos e melhoram modularidade.

Exemplo em Python:

```python
def minha_funcao():
    x = 10  *# variável local*
    print(x)

minha_funcao()
*# print(x)  # Isso causaria erro: x não está definido fora da função*
```

---

### 8.4.2 Escopo Global

- Variáveis globais são declaradas fora de funções e podem ser acessadas em qualquer parte do programa.
- Para modificar variáveis globais dentro de funções, usa-se a palavra-chave `global`.

Exemplo:

```python
contador = 0  *# variável global*

def incrementar():
    global contador
    contador += 1

incrementar()
print(contador)  *# 1*
```

Se não usar `global` ao tentar modificar o valor dentro da função, Python cria uma nova variável local com mesmo nome.

---

### 8.4.3 Escopo de Bloco

- Em Python, variáveis declaradas dentro de blocos como `if`, `for` ou `while` pertencem ao escopo da função, ou seja, não são limitadas ao bloco.
- Entretanto, o conceito de escopo de bloco é relevante em outras linguagens como C, Java, etc.

Exemplo em Python:

```python
if True:
    x = 5  *# x está no escopo da função ou módulo*

print(x)  *# 5, acessível fora do bloco if*
```

Em linguagens com escopo de bloco restrito, variáveis definidas dentro do bloco não são acessíveis fora dele.

## 8.5 Gerenciamento de Memória

---

### 8.5.1 Stack vs Heap

- **Stack (Pilha):**
    
    Área da memória para armazenamento temporário de dados de execução, como variáveis locais e chamadas de função.
    
    Funciona em ordem LIFO (Last In, First Out).
    
    Quando uma função é chamada, seu contexto é empilhado; ao terminar, é desempilhado.
    
    Rápido e organizado, porém de tamanho limitado.
    
- **Heap:**
    
    Região usada para alocação dinâmica, onde objetos e dados variáveis (listas, dicionários, instâncias) são armazenados.
    
    Objetos no heap permanecem enquanto houver referências a eles.
    
    Menos organizado que a stack, mas permite maior flexibilidade.
    

Em Python:

- Variáveis locais e chamadas estão na stack, mas os objetos associados (ex: listas) residem na heap.
- O nome da variável na stack referencia o objeto na heap.

Exemplo:

```python
def func():
    a = [1, 2, 3]  *# 'a' na stack, lista na heap*
    return a

lst = func()  *# lst referencia a lista na heap*
```

---

### 8.5.2 Garbage Collection

- Processo automático que identifica e libera memória dos objetos que não têm mais referências.
- Python usa **contagem de referências** e **coletor generacional** para eficiência.
- Contagem de referências: cada objeto mantém um contador de quantas referências apontam para ele. Quando chega a zero, memória é liberada automaticamente.
- Coletor generacional: otimiza a coleta focando em objetos jovens, que têm maior chance de serem descartados rapidamente.

---

### 8.5.3 Ponteiros e Referências

- Python não expõe ponteiros diretamente, mas usa o conceito de **referências** para acessar objetos na heap.
- Variáveis armazenam referências (endereços indiretos) a objetos na memória.
- Modificar um objeto referenciado afeta todas as variáveis que apontam para ele.

Exemplo:

```python
a = [1, 2, 3]
b = a          *# b e a referenciam o mesmo objeto*
b.append(4)
print(a)       *# [1, 2, 3, 4], alteração refletida em 'a'*
```
