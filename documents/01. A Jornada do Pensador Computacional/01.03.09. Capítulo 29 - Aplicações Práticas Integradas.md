## 29.1 Sistemas de Recomendação

---

### 29.1.1 Collaborative Filtering

- Técnica que recomenda itens a um usuário com base em preferências e avaliações de usuários similares.
- Depende do histórico coletivo de interações (ex. avaliações, cliques).
- Pode ser baseada em usuários (user-based) ou itens (item-based).

### 29.1.2 Content-based Filtering

- Recomenda itens semelhantes aos que o usuário já gostou, baseando-se nas características dos próprios itens.
- Usa descritores, metadados ou representações vetoriais para medir similaridade.

### 29.1.3 Álgebra Linear Aplicada

- Técnicas como decomposição de matrizes e SVD (singular value decomposition) são usadas para reduzir dimensionalidade e extrair características latentes.
- Essenciais para sistemas baseados em filtros colaborativos model-based.

---

### Exemplo prático simplificado de Collaborative Filtering com Matriz de Usuários-Itens em Python

```python
import numpy as np
from sklearn.metrics.pairwise import cosine_similarity

*# Matriz Usuário-Item (exemplo pequeno)*
ratings = np.array([
    [5, 3, 0, 1],
    [4, 0, 0, 1],
    [1, 1, 0, 5],
    [0, 0, 5, 4],
    [0, 1, 5, 4],
])

*# Similaridade entre usuários*
user_sim = cosine_similarity(ratings)

print("Similaridade entre usuários:")
print(user_sim)
```

## 29.3 Processamento de Imagens

---

### 29.3.1 Representação Digital

- Imagens são representadas como matrizes digitais, onde cada elemento (pixel) possui valores (tons de cinza ou cores RGB).
- Resolução e profundidade de cor impactam qualidade e tamanho de imagem.

---

### 29.3.2 Filtros e Convolução

- Operações aplicadas para modificar ou extrair características da imagem.
- Convolução envolve aplicação de um kernel (matriz pequena) que percorre a imagem, realizando somas ponderadas.
- Usado para suavização, nitidez, detecção de bordas.

Exemplo Python com OpenCV (filtro de blur):

```python
import cv2
import numpy as np
imagem = cv2.imread('imagem.jpg')
blur = cv2.GaussianBlur(imagem, (5,5), 0)
cv2.imwrite('imagem_blur.jpg', blur)
```

---

### 29.3.3 Transformadas (Fourier)

- Transformada de Fourier analisa a frequência na imagem.
- Frequências altas correspondem a detalhes; baixas a regiões suaves.
- Usada para filtragem, compressão e análise de textura.

---

### 29.3.4 Algoritmos de Compressão

- Reduzem o tamanho da imagem para armazenamento/transmissão.
- Técnicas incluem compressão com e sem perdas (JPEG, PNG).
- Algoritmos exploram redundância espacial e espectral.

## 29.5 Bioinformática Computacional

---

### 29.5.1 Alinhamento de Sequências

- Processo de organizar sequências de DNA, RNA ou proteínas para identificar regiões de similaridade, que indicam relações evolutivas ou funcionais.
- Alinhamento global (Needleman-Wunsch): busca melhor alinhamento na totalidade das sequências.
- Alinhamento local (Smith-Waterman): destaca regiões locais altamente similares.
- Baseado em programação dinâmica, que otimiza pontuação considerando matches, mismatches e gaps.

Exemplo simplificado do alinhamento global (pontuação binária) em Python:

```python
def alinhamento_global(s, t, match=1, mismatch=-1, gap=-1):
    m, n = len(s), len(t)
    dp = [[0]*(n+1) for _ in range(m+1)]

    for i in range(m+1):
        dp[i][0] = i * gap
    for j in range(n+1):
        dp[0][j] = j * gap

    for i in range(1, m+1):
        for j in range(1, n+1):
            if s[i-1] == t[j-1]:
                score_diag = dp[i-1][j-1] + match
            else:
                score_diag = dp[i-1][j-1] + mismatch
            dp[i][j] = max(score_diag, dp[i-1][j] + gap, dp[i][j-1] + gap)
    return dp[m][n]

seq1 = "ACGTG"
seq2 = "ACGTC"
print(alinhamento_global(seq1, seq2))
```

### 29.5.2 Árvores Filogenéticas

- Representam relações evolutivas entre organismos ou genes.
- Construídas a partir de dados de alinhamento, analisando similaridades e divergências.
- Métodos incluem agrupamento hierárquico, distância e máxima verossimilhança.

---

### 29.5.3 Algoritmos em Strings Biológicas

- Análise complexa de sequências requer busca eficiente, comparação e extração de padrões.
- Métodos incluem algoritmos de busca em strings, índice FM, trie e hash para buscas rápidas e montagem de genomas.
- Utilizados também em análise de expressões regulares e motifs funcionais.
