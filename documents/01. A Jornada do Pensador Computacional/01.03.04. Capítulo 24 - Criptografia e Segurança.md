## 24.1 Matemática da Criptografia

---

### 24.1.1 Aritmética Modular

- Operações matemáticas realizadas com números inteiros sob um módulo nnn.
- Muito utilizada em criptografia para limitar valores e criar ciclos.
- Operações comuns: adição, subtração, multiplicação e exponenciação módulo nnn.

Exemplo em Python:

```python
def mod_exp(base, expoente, modulo):
    resultado = 1
    base = base % modulo
    while expoente > 0:
        if expoente % 2 == 1:
            resultado = (resultado * base) % modulo
        expoente = expoente // 2
        base = (base * base) % modulo
    return resultado

print(mod_exp(3, 200, 13))  *# Saída: 3^200 mod 13*
```

### 24.1.2 Números Primos

- Números naturais maiores que 1 que possuem apenas dois divisores: 1 e ele mesmo.
- Fundamentais para criptografia assimétrica (como RSA).
- Crivo de Eratóstenes é um método eficiente para gerar números primos até um limite.

Exemplo Crivo de Eratóstenes em Python:

```python
def crivo_eratostenes(n):
    primos = [True] * (n+1)
    primos[0], primos[1] = False, False
    for i in range(2, int(n**0.5) + 1):
        if primos[i]:
            for j in range(i*i, n+1, i):
                primos[j] = False
    return [i for i in range(n+1) if primos[i]]

print(crivo_eratostenes(50))  *# Saída: todos os primos até 50*
```

### 24.1.3 Algoritmo de Euclides Estendido

- Extensão do algoritmo de Euclides para encontrar coeficientes da identidade de Bézout:
    
    $ax + by = \gcd(a, b)$
    
- Usado para calcular inversos multiplicativos módulo $n$, essencial em criptografia.

Exemplo Python:

```python
def euclides_estendido(a, b):
    if b == 0:
        return a, 1, 0
    d, x1, y1 = euclides_estendido(b, a % b)
    x = y1
    y = x1 - (a // b) * y1
    return d, x, y

d, x, y = euclides_estendido(240, 46)
print(f"gcd: {d}, x: {x}, y: {y}")  *# Output: gcd: 2, x, y valores*
```

## 24.2 Criptografia Simétrica

---

### 24.2.1 Cifras de Substituição

- Substituem caracteres do texto original por outros caracteres.
- Exemplo clássico: **Cifra de César**, onde cada letra é deslocada no alfabeto por um número fixo de posições.

Exemplo simples da Cifra de César em Python:

```python
def cifra_cesar(texto, deslocamento):
    resultado = ""
    for char in texto:
        if char.isalpha():
            base = 'A' if char.isupper() else 'a'
            resultado += chr((ord(char) - ord(base) + deslocamento) % 26 + ord(base))
        else:
            resultado += char
    return resultado

texto = "Criptografia Simetrica"
deslocamento = 3
texto_cifrado = cifra_cesar(texto, deslocamento)
print(texto_cifrado)  *# Fulswrijudold Vlphwulfd*
```

---

### 24.2.2 Cifras de Transposição

- Reorganizam a ordem dos caracteres no texto original, sem alterar os caracteres em si.
- Exemplo: **Cifra Rail Fence**, onde o texto é escrito em forma zig-zag em linhas e lido por linha.

---

### 24.2.3 DES e AES

- **DES (Data Encryption Standard):** algoritmo simétrico antigo, utiliza blocos de 64 bits e chave de 56 bits.
- **AES (Advanced Encryption Standard):** padrão atual, suporta chaves de 128, 192 e 256 bits, muito mais seguro e eficiente.

Uso de bibliotecas Python para AES:

```python
from Crypto.Cipher import AES
from Crypto.Random import get_random_bytes
from Crypto.Util.Padding import pad, unpad

chave = get_random_bytes(16)  *# 128 bits*
cipher = AES.new(chave, AES.MODE_CBC)
dados = b"Mensagem secreta"
dados_padded = pad(dados, AES.block_size)
ciphertext = cipher.encrypt(dados_padded)

print("Cifrado:", ciphertext)

decipher = AES.new(chave, AES.MODE_CBC, cipher.iv)
decrypted_padded = decipher.decrypt(ciphertext)
decrypted = unpad(decrypted_padded, AES.block_size)

print("Decifrado:", decrypted.decode())
```

## 24.4 Hash Functions

---

### 24.4.1 Propriedades Criptográficas

- **Determinística:** mesma entrada gera sempre o mesmo hash.
- **Resistência à pré-imagem:** dado um hash, é computacionalmente inviável descobrir a entrada original.
- **Resistência à segunda pré-imagem:** dada uma entrada, é difícil encontrar outra distinta com o mesmo hash.
- **Resistência à colisão:** dificulta encontrar duas entradas diferentes com o mesmo hash.
- **Efeito Avalanche:** pequenas mudanças na entrada geram grandes mudanças no hash.

---

### 24.4.2 MD5, SHA-1, SHA-256

- **MD5:** hash de 128 bits, rápido mas hoje considerado quebrado para segurança.
- **SHA-1:** hash de 160 bits, mais seguro que o MD5, mas também vulnerável a colisões modernas.
- **SHA-256:** parte da família SHA-2, oferece hash de 256 bits, atualmente amplamente usado e seguro.

---

### 24.4.3 Aplicações Práticas

- **Integridade de dados:** verificar se arquivos são idênticos ao original.
- **Armazenamento seguro de senhas:** armazenar hashes de senhas ao invés das senhas.
- **Assinaturas digitais e autenticação:** validar identidade e integridade de mensagens.
- **Identificação em sistemas distribuídos:** deduplicação, verificação rápida.

---

### Exemplo prático com hashlib em Python

```python
import hashlib

mensagem = "Mensagem importante"
hash_md5 = hashlib.md5(mensagem.encode()).hexdigest()
hash_sha1 = hashlib.sha1(mensagem.encode()).hexdigest()
hash_sha256 = hashlib.sha256(mensagem.encode()).hexdigest()

print("MD5:", hash_md5)
print("SHA-1:", hash_sha1)
print("SHA-256:", hash_sha256)
```
