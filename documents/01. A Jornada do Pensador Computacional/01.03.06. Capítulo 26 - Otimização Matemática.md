## 26.1 Programação Linear

---

### 26.1.1 Formulação de Problemas

- Consiste em maximizar ou minimizar uma função linear chamada função objetivo:
    
    $\text{Maximize (ou Minimize)}\quad c^T x$
    
- Sujeita a restrições lineares, que formam um poliedro viável:
    
    $A x \leq b \quad \text{ou} \quad A x = b$
    
- Variáveis xxx geralmente são não-negativas.

---

### 26.1.2 Método Simplex (Conceitos)

- Algoritmo iterativo para resolver problemas de programação linear.
- Funciona caminhando nos vértices do poliedro viável, melhorando a função objetivo a cada passo.
- Passos principais:
    1. Encontrar uma solução básica inicial viável.
    2. Avaliar se a solução é ótima.
    3. Selecionar variável para entrar na base (melhorar objetivo).
    4. Selecionar variável para sair da base para manter viabilidade.
    5. Atualizar tabela (tableau) do Simplex.
    6. Repetir até encontrar a solução ótima.

---

### 26.1.3 Dualidade

- Todo problema primal tem um problema dual associado.
- Propriedades importantes:
    - Otimização primal e dual tem o mesmo valor ótimo (em condições regulares).
    - Solução do dual fornece limites para a solução do primal.
- Útil para análise de sensibilidade e algoritmos.

## 26.2 Métodos de Otimização

---

### 26.2.1 Gradient Descent

- Método iterativo para minimizar uma função diferenciável.
- Atualiza parâmetros na direção do gradiente negativo da função com uma taxa de aprendizado.
- Amplamente usado em treinamento de modelos de machine learning.

```python
def gradient_descent(f_grad, x0, taxa, iteracoes):
    x = x0
    for _ in range(iteracoes):
        grad = f_grad(x)
        x = x - taxa * grad
    return x

*# Exemplo: minimize f(x)=x^2, grad = 2*x*
def grad_f(x):
    return 2*x

print(gradient_descent(grad_f, 10, 0.1, 100))  *# Aproxima zero*
```

---

### 26.2.2 Newton-Raphson

- Método iterativo usando primeira e segunda derivadas para encontrar raízes.
- Pode ser adaptado para otimização.
- Converge mais rápido que Gradient Descent quando bem condicionado.

```python
def newton_raphson(f_grad, f_hess, x0, iteracoes):
    x = x0
    for _ in range(iteracoes):
        grad = f_grad(x)
        hess = f_hess(x)
        x = x - grad / hess
    return x

*# Exemplo: f(x)=x^2, grad=2x, hess=2*
def grad_f(x):
    return 2*x
def hess_f(x):
    return 2

print(newton_raphson(grad_f, hess_f, 10, 10))
```

- Heurísticas inspiradas em evolução natural.
- Usam populações, seleção, mutação e cruzamento para explorar espaço solução.
- Usados onde funções são complexas, não deriváveis.

### 26.3.1 Machine Learning

- Otimização é fundamental no treinamento de modelos para minimizar funções de perda.
- Exemplos comuns incluem regressão linear, redes neurais, e SVMs que usam algoritmos como Gradient Descent e variantes aprimoradas.
- Ajuste de hiperparâmetros e seleção de modelos também envolvem otimização.

Exemplo Python (ajuste linear simplificado):

```python
import numpy as np

*# Dados*
X = np.array([1, 2, 3, 4, 5])
Y = np.array([3, 4, 2, 5, 6])

*# Função de custo MSE*
def mse(theta, X, Y):
    return np.mean((Y - (theta[0] + theta[1]*X))**2)

*# Gradiente*
def grad_mse(theta, X, Y):
    n = len(Y)
    grad0 = -2*np.sum(Y - (theta[0] + theta[1]*X))/n
    grad1 = -2*np.sum(X*(Y - (theta[0] + theta[1]*X)))/n
    return np.array([grad0, grad1])

*# Gradient Descent*
theta = np.array([0.0, 0.0])
alpha = 0.01
for _ in range(1000):
    theta -= alpha * grad_mse(theta, X, Y)
print(f"Parâmetros ajustados: {theta}")
```
