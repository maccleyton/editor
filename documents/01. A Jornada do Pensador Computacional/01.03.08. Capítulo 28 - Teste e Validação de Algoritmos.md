## 28.1 Estratégias de Teste

---

### 28.1.1 Teste de Caixa Preta

- Testa funcionalidade sem considerar a estrutura interna do algoritmo.
- Foca nas entradas e saídas; o testador não conhece o código.
- Técnicas comuns: partição de equivalência, análise de valor limite, tabelas de decisão.

Exemplo simples:

- Para uma função que aceita idades 18+, testa-se as idades 17, 18 e 19 para garantir o comportamento correto nos limites.

---

### 28.1.2 Teste de Caixa Branca

- Testa o funcionamento interno do código, baseado na estrutura, lógica e caminhos.
- Testa todos os caminhos possíveis, condições de decisão, estruturas de repetição.
- Requer conhecimento do código e foco na cobertura.

Exemplo:

- Testar se todas as ramificações do código estão sendo executadas pelo menos uma vez.

---

### 28.1.3 Casos de Teste Extremos

- Testes com dados nas aplicações máximas ou mínimas, ou situações inimagináveis, para garantir robustez.
- Testa comportamentos sob limite da capacidade, tempos extremos ou entradas inválidas.

---

### 28.1.4 Teste de Stress

- Submete o algoritmo a cargas elevadas, volumes grandes de dados ou condições limitantes.
- Verifica desempenho, uso de memória e resistência a falhas sob pressão.

---

## 28.2 Verificação de Corretude

---

### 28.2.1 Invariantes de Laço

- Propriedades que permanecem verdadeiras antes e após cada iteração de um laço.
- Usados para provar a correção de algoritmos iterativos.

---

### 28.2.2 Pré e Pós-condições

- Condições que devem ser verdadeiras antes da execução (pré) e após a execução (pós) de uma função.
- Auxiliam no design correto e na prova formal do algoritmo.

---

### 28.2.3 Prova Formal de Algoritmos

- Método matemático rigoroso para demonstrar que um algoritmo corresponde à especificação desejada.
- Utilizado em algoritmos críticos e segurança da informação.

---

### Exercício Prático Exemplo: Teste de Caixa Preta Simples em Python

```python
def eh_maioridade(idade):
    if idade >= 18:
        return True
    else:
        return False

*# Casos de teste limites*
testes = [17, 18, 19]

for t in testes:
    print(f"Idade: {t}, Maioridade? {eh_maioridade(t)}")
```

## 28.3 Debugging Matemático

---

### 28.3.1 Análise de Erro Numérico

- Erros surgem em cálculos devido à representação finita de números reais em computadores (ponto flutuante).
- Tipos de erros: truncamento e arredondamento.
- Importante para entender limitações e evitar propagação crescente de erros.

---

### 28.3.2 Problemas de Precisão

- Algoritmos podem apresentar resultados imprecisos por:
    - Perda de significância em subtrações de números próximos.
    - Instabilidade numérica em algoritmos mal estruturados.
- Exemplo clássico: cálculo de raízes usando fórmulas que envolvem subtração próxima de valores grandes.

---

### 28.3.3 Edge Cases Matemáticos

- Casos especiais nos dados que podem gerar comportamento atípico ou erros.
- Exemplo: divisão por zero, valores infinitos, números muito grandes ou muito pequenos.
- Identificar e tratar esses casos é fundamental para robustez.

---

### Exemplo Python: Cálculo Numérico com Consideração de Erros

```python
import math

def raiz_quadrada_cuidadosa(a, b, c):
    delta = b*b - 4*a*c
    if delta < 0:
        return None
    sqrt_delta = math.sqrt(delta)
    if b > 0:
        x1 = (-b - sqrt_delta) / (2 * a)
        x2 = (2 * c) / (-b - sqrt_delta)
    else:
        x1 = (-b + sqrt_delta) / (2 * a)
        x2 = (2 * c) / (-b + sqrt_delta)
    return x1, x2

print(raiz_quadrada_cuidadosa(1, 1e8, 1))  *# Evita perda de significância*
```

## 28.4 Benchmarking

---

### 28.4.1 Medição de Performance

- Avaliação do tempo de execução e uso de recursos computacionais.
- Ferramentas como `timeit` em Python permitem medir desempenho preciso.

---

### 28.4.2 Profiling de Código

- Análise detalhada da execução, identificando gargalos e consumo de CPU/memória.
- Ferramentas: `cProfile`, `line_profiler`.

---

### 28.4.3 Análise Estatística de Resultados

- Uso de estatísticas para resumo e comparação de benchmarks.
- Análise de média, variância, boxplots para entender comportamento sob diferentes cargas.

---

### Exemplo Python: Benchmarking Simples

```python
import timeit
codigo = """
lista = list(range(1000))
lista.reverse()
"""
tempo = timeit.timeit(codigo, number=1000)
print(f"Tempo médio execução: {tempo:.6f} segundos")
```
