## 7.1 Sequência

---

### 7.1.1 Execução Linear

- A execução linear significa que as instruções do programa são executadas uma após a outra, na ordem em que aparecem.

Exemplo em pseudocódigo:

```bash
INÍCIO
    A ← 10
    B ← 20
    C ← A + B
    IMPRIMIR C
FIM
```

Em Python:

```python
A = 10
B = 20
C = A + B
print(C)  *# 30*
```

---

### 7.1.2 Atribuições

- Atribuição é a operação de armazenar um valor em uma variável, que poderá ser usada posteriormente.

Exemplo:

```python
x = 5
y = x + 2  *# y receberá 7*
```

- É a base para manipular dados em programa.

---

### 7.1.3 Entrada e Saída de Dados

- Entrada: permite ao programa receber dados fornecidos pelo usuário ou outras fontes.
- Saída: exibe resultados ou informações produzidas.

Exemplo em Python:

```python
nome = input("Digite seu nome: ")
print("Olá, " + nome)
```

Em pseudocódigo:

```bash
LER nome
IMPRIMIR "Olá, " + nome
```

## 7.2 Estruturas Condicionais

Estruturas condicionais permitem que programas tomem decisões baseadas em condições lógicas, alterando o fluxo de execução.

---

### 7.2.1 Condicional Simples (IF)

- Executa um bloco se a condição for verdadeira.

Pseudocódigo:

```bash
INÍCIO
    LER numero
    SE numero > 0 ENTÃO
        IMPRIMIR "Número positivo"
    FIM SE
FIM
```

Python:

```python
numero = int(input("Digite um número: "))
if numero > 0:
    print("Número positivo")
```

---

### 7.2.2 Condicional Composta (IF-ELSE)

- Escolhe entre dois blocos, um para condição verdadeira e outro para falsa.

Pseudocódigo:

```bash
INÍCIO
    LER numero
    SE numero > 0 ENTÃO
        IMPRIMIR "Positivo"
    SENÃO
        IMPRIMIR "Não positivo"
    FIM SE
FIM
```

Python:

```python
numero = int(input("Digite um número: "))
if numero > 0:
    print("Positivo")
else:
    print("Não positivo")
```

---

### 7.2.3 Condicionais Aninhadas

- Condições dentro de condições, para múltiplas decisões.

Pseudocódigo:

```bash
INÍCIO
    LER idade
    SE idade < 0 ENTÃO
        IMPRIMIR "Idade inválida"
    SENÃO
        SE idade >= 18 ENTÃO
            IMPRIMIR "Maior de idade"
        SENÃO
            IMPRIMIR "Menor de idade"
        FIM SE
    FIM SE
FIM
```

Python:

```python
idade = int(input("Digite sua idade: "))
if idade < 0:
    print("Idade inválida")
else:
    if idade >= 18:
        print("Maior de idade")
    else:
        print("Menor de idade")
```

---

### 7.2.4 Estrutura de Múltipla Escolha (SWITCH/CASE)

- Seleciona um bloco dentre vários possíveis com base no valor de uma variável.

Exemplo em pseudocódigo:

```bash
INÍCIO
    LER dia
    ESCOLHA dia
        CASO 1: IMPRIMIR "Domingo"
        CASO 2: IMPRIMIR "Segunda"
        ...
        CASO CONTRÁRIO: IMPRIMIR "Dia inválido"
    FIM ESCOLHA
FIM
```

Em Python (equivalente com `dict`):

```python
def dia_semana(dia):
    switcher = {
        1: "Domingo",
        2: "Segunda-feira",
        3: "Terça-feira",
        *# ...*
    }
    return switcher.get(dia, "Dia inválido")

dia = int(input("Digite o número do dia: "))
print(dia_semana(dia))
```

---

### 7.2.5 Operador Ternário

- Expressão condensada para condição simples, útil para atribuir valores.

Python:

```python
numero = int(input("Digite um número: "))
resultado = "Positivo" if numero > 0 else "Não positivo"
print(resultado)
```

## 7.3 Estruturas de Repetição

Repetições permitem executar um bloco de código várias vezes, o que é fundamental para automação, iteração sobre coleções e algoritmos iterativos.

---

### 7.3.1 Laços com Teste no Início (WHILE)

- O laço **while** testa a condição antes de executar o bloco.

Pseudocódigo:

```bash
INÍCIO
    i ← 1
    Enquanto i <= 5 faça
        Imprimir i
        i ← i + 1
    Fim Enquanto
FIM
```

Python:

```python
i = 1
while i <= 5:
    print(i)
    i += 1
```

---

### 7.3.2 Laços com Teste no Final (DO-WHILE)

- Executa o bloco pelo menos uma vez e testa a condição após.

Pseudocódigo:

```bash
INÍCIO
    i ← 1
    Faça
        Imprimir i
        i ← i + 1
    Enquanto i <= 5
FIM
```

Python não possui do-while nativo, mas pode ser simulado:

```python
i = 1
while True:
    print(i)
    i += 1
    if not (i <= 5):
        break
```

---

### 7.3.3 Laços Contados (FOR)

- Itera um número definido de vezes.

Pseudocódigo:

```bash
INÍCIO
    Para i de 1 até 5 faça
        Imprimir i
    Fim Para
FIM
```

Python:

```python
for i in range(1, 6):
    print(i)
```

---

### 7.3.4 Laços Aninhados

- Uso de laços dentro de laços, para operações mais complexas (ex.: matrizes).

Exemplo pseudocódigo:

```bash
INÍCIO
    Para i de 1 até 3 faça
        Para j de 1 até 3 faça
            Imprimir i, j
        Fim Para
    Fim Para
FIM
```

Python:

```python
for i in range(1, 4):
    for j in range(1, 4):
        print(i, j)
```

---

### 7.3.5 Controle de Laços (BREAK, CONTINUE)

- **BREAK:** sai imediatamente do laço.
- **CONTINUE:** pula a iteração atual e vai para a próxima.

Exemplo:

```python
for i in range(1, 6):
    if i == 3:
        continue  *# pula o número 3*
    if i == 5:
        break  *# sai do laço ao chegar em 5*
    print(i)
```

Saída:

```bash
1
2
4
```

## 7.4 Tratamento de Exceções

---

### 7.4.1 TRY-CATCH-FINALLY

- **TRY:** bloco onde se coloca o código que pode gerar exceções (erros).
- **CATCH (except em Python):** captura e trata a exceção se ocorrer.
- **FINALLY:** código que sempre será executado, independente de erro ocorrer ou não, ideal para liberar recursos.

Exemplo em Python:

```python
try:
    x = int(input("Digite um número: "))
    y = int(input("Digite outro número: "))
    resultado = x / y
except ZeroDivisionError:
    print("Erro: Não é possível dividir por zero!")
except ValueError:
    print("Erro: Entrada inválida! Digite apenas números.")
else:
    print(f"O resultado é: {resultado}")
finally:
    print("Execução finalizada.")
```

---

### 7.4.2 Propagação de erros

- Se uma exceção não for capturada em um bloco, ela se propaga para o chamador, podendo interromper a execução do programa.
- É importante tratar exceções nos níveis corretos para evitar falhas inesperadas.
- Em funções, pode-se lançar exceções customizadas para informar erros específicos.

Exemplo de lançamento de exceção:

```python
def dividir(a, b):
    if b == 0:
        raise ValueError("Divisor não pode ser zero!")
    return a / b

try:
    print(dividir(10, 0))
except ValueError as e:
    print(f"Erro capturado: {e}")
```

---

### 7.4.3 Validação Preventiva

- Antes de operações que podem falhar, faça validações para evitar exceções.
- Reduz a necessidade de tratar erros depois, melhorando desempenho e clareza.

Exemplo:

```python
x = input("Digite um número: ")
if x.isdigit():
    numero = int(x)
    print(f"Número digitado: {numero}")
else:
    print("Entrada inválida, por favor digite apenas números.")
```
