# 🧮 G. Glossário de Termos

---

## Referência Técnica Abrangente

Este glossário consolida a terminologia essencial em lógica, matemática, algoritmos e programação, fornecendo definições precisas e contexto para facilitar a compreensão e comunicação técnica.

---

## G.1 Termos de Lógica

### Lógica Proposicional

**Axioma**

Proposição fundamental aceita como verdadeira sem necessidade de demonstração. Base para derivação de teoremas e provas matemáticas.

**Bicondicional**

Conectivo lógico "se e somente se" (↔). A proposição p ↔ q é verdadeira quando p e q têm o mesmo valor de verdade.

**Conjunção**

Operador lógico "e" (∧). A proposição p ∧ q é verdadeira apenas quando ambas p e q são verdadeiras.

**Condicional**

Operador lógico "se...então" (→). A proposição p → q é falsa apenas quando p é verdadeira e q é falsa.

**Contraposição**

Transformação lógica onde p → q é equivalente a ¬q → ¬p. Útil em provas matemáticas.

**Disjunção**

Operador lógico "ou" (∨). A proposição p ∨ q é verdadeira quando pelo menos uma das proposições é verdadeira.

**Disjunção Exclusiva**

Operador "ou exclusivo" (⊕). A proposição p ⊕ q é verdadeira quando exatamente uma das proposições é verdadeira.

**Implicação**

Relação lógica entre antecedente e consequente. Se p implica q, então p → q.

**Modus Ponens**

Regra de inferência: se p → q e p são verdadeiras, então q é verdadeira.

**Modus Tollens**

Regra de inferência: se p → q e ¬q são verdadeiras, então ¬p é verdadeira.

**Negação**

Operador lógico "não" (¬). ¬p tem valor de verdade oposto ao de p.

**Proposição**

Declaração que pode ser classificada como verdadeira ou falsa, mas não ambas.

**Quantificador Existencial**

Símbolo ∃ que indica "existe pelo menos um". ∃x P(x) significa "existe x tal que P(x) é verdadeiro".

**Quantificador Universal**

Símbolo ∀ que indica "para todo". ∀x P(x) significa "para todo x, P(x) é verdadeiro".

**Satisfatibilidade**

Propriedade de fórmula lógica que pode ser verdadeira sob alguma interpretação. Base do problema SAT.

**Tautologia**

Proposição que é sempre verdadeira, independentemente dos valores de verdade de suas variáveis.

### Lógica de Predicados

**Predicado**

Função que retorna valor de verdade. P(x) é um predicado sobre x.

**Domínio**

Conjunto de valores sobre o qual quantificadores operam.

**Interpretação**

Atribuição de significado específico aos símbolos de uma fórmula lógica.

**Modelo**

Interpretação que torna uma fórmula verdadeira.

**Unificação**

Processo de encontrar substituições que tornam duas expressões idênticas.

## G.2 Termos Matemáticos

### Teoria dos Conjuntos

**Cardinalidade**

Número de elementos em um conjunto finito. Denotada por |A| para conjunto A.

**Complemento**

Conjunto de elementos que não pertencem ao conjunto dado. A^c = U \ A onde U é o universo.

**Diferença Simétrica**

Conjunto de elementos que pertencem a exatamente um dos dois conjuntos. A △ B = (A \ B) ∪ (B \ A).

**Interseção**

Conjunto de elementos comuns a dois ou mais conjuntos. A ∩ B.

**Partição**

Divisão de conjunto em subconjuntos disjuntos e não-vazios cuja união é o conjunto original.

**Produto Cartesiano**

Conjunto de pares ordenados. A × B = {(a,b) | a ∈ A, b ∈ B}.

**Relação de Equivalência**

Relação reflexiva, simétrica e transitiva que particiona conjunto em classes de equivalência.

**Subconjunto**

Conjunto A é subconjunto de B (A ⊆ B) se todo elemento de A também pertence a B.

**União**

Conjunto de elementos que pertencem a pelo menos um dos conjuntos dados. A ∪ B.

### Funções e Relações

**Bijeção**

Função que é simultaneamente injetiva e sobrejetiva. Estabelece correspondência um-para-um.

**Domínio**

Conjunto de valores de entrada de uma função.

**Função Inversa**

Função f^(-1) tal que f^(-1)(f(x)) = x para todo x no domínio de f.

**Injeção**

Função onde elementos distintos do domínio mapeiam para elementos distintos do contradomínio.

**Imagem**

Conjunto de valores efetivamente assumidos por uma função.

**Sobrejeção**

Função onde todo elemento do contradomínio é imagem de pelo menos um elemento do domínio.

### Combinatória

**Arranjo**

Sequência ordenada de k elementos escolhidos de n elementos. A(n,k) = n!/(n-k)!.

**Combinação**

Seleção não-ordenada de k elementos de n elementos. C(n,k) = n!/(k!(n-k)!).

**Permutação**

Arranjo de todos os elementos de um conjunto. n! possibilidades para n elementos.

**Princípio da Inclusão-Exclusão**

Fórmula para calcular cardinalidade da união de conjuntos considerando interseções.

**Princípio da Casa dos Pombos**

Se n+1 objetos são colocados em n caixas, pelo menos uma caixa conterá mais de um objeto.

### Teoria dos Números

**Algoritmo de Euclides**

Método eficiente para calcular o máximo divisor comum de dois números inteiros.

**Congruência**

Relação de equivalência módulo um número. a ≡ b (mod n) se n divide (a-b).

**Máximo Divisor Comum (MDC)**

Maior inteiro positivo que divide dois ou mais números.

**Mínimo Múltiplo Comum (MMC)**

Menor inteiro positivo que é múltiplo de dois ou mais números.

**Número Primo**

Inteiro maior que 1 que tem exatamente dois divisores positivos: 1 e ele mesmo.

**Teorema Fundamental da Aritmética**

Todo inteiro maior que 1 pode ser representado de forma única como produto de primos.

### Probabilidade e Estatística

**Distribuição de Probabilidade**

Função que especifica a probabilidade de cada resultado possível em experimento aleatório.

**Esperança Matemática**

Valor médio esperado de variável aleatória. E[X] = Σ x·P(X=x).

**Evento**

Subconjunto do espaço amostral. Resultado ou conjunto de resultados de experimento.

**Independência**

Dois eventos são independentes se P(A∩B) = P(A)·P(B).

**Probabilidade Condicional**

Probabilidade de evento A dado que evento B ocorreu. P(A|B) = P(A∩B)/P(B).

**Variância**

Medida de dispersão de variável aleatória. Var(X) = E[(X-E[X])²].

## G.3 Termos Algorítmicos

### Análise de Complexidade

**Análise Amortizada**

Técnica que calcula o tempo médio por operação em sequência de operações.

**Big O (O)**

Notação que descreve limite superior assintótico da complexidade de algoritmo.

**Big Omega (Ω)**

Notação que descreve limite inferior assintótico da complexidade de algoritmo.

**Big Theta (Θ)**

Notação que descreve limite assintótico exato (superior e inferior) da complexidade.

**Complexidade de Espaço**

Quantidade de memória adicional requerida por algoritmo em função do tamanho da entrada.

**Complexidade de Tempo**

Número de operações básicas executadas por algoritmo em função do tamanho da entrada.

**Little o (o)**

Notação que indica crescimento assintótico estritamente menor.

**Little omega (ω)**

Notação que indica crescimento assintótico estritamente maior.

### Técnicas Algorítmicas

**Algoritmo Ganancioso (Greedy)**

Técnica que faz escolha localmente ótima em cada passo, esperando encontrar ótimo global.

**Algoritmo Randomizado**

Algoritmo que faz escolhas aleatórias durante execução. Pode ser Monte Carlo ou Las Vegas.

**Backtracking**

Técnica que explora soluções parciais e abandona caminhos que não podem levar à solução.

**Busca Binária**

Algoritmo de busca em array ordenado que divide espaço de busca pela metade a cada iteração.

**Divisão e Conquista**

Técnica que divide problema em subproblemas menores, resolve recursivamente e combina soluções.

**Força Bruta**

Abordagem que testa todas as possibilidades para encontrar solução, sem otimizações.

**Programação Dinâmica**

Técnica que resolve problemas dividindo em subproblemas sobrepostos e armazenando soluções.

### Estruturas de Dados

**Árvore Balanceada**

Árvore onde diferença de altura entre subárvores é limitada, garantindo operações eficientes.

**Árvore Binária de Busca**

Árvore binária onde elementos da subárvore esquerda são menores que raiz e da direita são maiores.

**Fila (Queue)**

Estrutura FIFO (First In, First Out) onde inserções ocorrem em uma extremidade e remoções na outra.

**Fila de Prioridade**

Estrutura onde elementos têm prioridades associadas e elemento de maior prioridade é removido primeiro.

**Grafo**

Estrutura composta por vértices (nós) conectados por arestas (links).

**Hash Table**

Estrutura que mapeia chaves para valores usando função hash para acesso eficiente.

**Heap**

Árvore binária completa onde cada nó satisfaz propriedade de heap (max-heap ou min-heap).

**Lista Ligada**

Estrutura linear onde elementos (nós) contêm dados e referência para próximo elemento.

**Pilha (Stack)**

Estrutura LIFO (Last In, First Out) onde inserções e remoções ocorrem na mesma extremidade.

### Algoritmos em Grafos

**Busca em Largura (BFS)**

Algoritmo que explora grafo nível por nível, visitando todos vizinhos antes de avançar.

**Busca em Profundidade (DFS)**

Algoritmo que explora grafo seguindo caminho até não poder avançar, então retrocede.

**Caminho Mínimo**

Problema de encontrar caminho de menor custo entre dois vértices em grafo ponderado.

**Componente Fortemente Conexa**

Subgrafo maximal onde existe caminho de qualquer vértice para qualquer outro vértice.

**Ciclo Hamiltoniano**

Ciclo que visita cada vértice do grafo exatamente uma vez e retorna ao vértice inicial.

**Fluxo Máximo**

Problema de determinar maior quantidade de fluxo que pode ser enviada de fonte para destino.

**Ordenação Topológica**

Ordenação linear de vértices de grafo acíclico dirigido respeitando dependências.

## G.4 Termos de Programação

### Paradigmas de Programação

**Programação Estruturada**

Paradigma que usa estruturas de controle bem definidas (sequência, seleção, iteração).

**Programação Orientada a Objetos**

Paradigma baseado em objetos que encapsulam dados e comportamentos.

**Programação Funcional**

Paradigma que trata computação como avaliação de funções matemáticas.

**Programação Imperativa**

Paradigma que usa comandos que alteram estado do programa.

**Programação Declarativa**

Paradigma que expressa lógica da computação sem descrever fluxo de controle.

### Conceitos de Linguagens

**Compilação**

Processo de traduzir código fonte para código de máquina antes da execução.

**Interpretação**

Processo de executar código fonte diretamente, linha por linha, durante runtime.

**Tipagem Dinâmica**

Sistema onde tipo de variável é determinado durante execução do programa.

**Tipagem Estática**

Sistema onde tipo de variável é determinado durante compilação.

**Polimorfismo**

Capacidade de usar interface uniforme para diferentes tipos de dados subjacentes.

**Encapsulamento**

Princípio de ocultar detalhes internos de implementação e expor apenas interface necessária.

**Herança**

Mecanismo onde classe deriva propriedades e comportamentos de classe pai.

**Abstração**

Processo de ocultar complexidade de implementação e mostrar apenas funcionalidade essencial.

### Estruturas de Controle

**Condicional**

Estrutura que executa diferentes blocos de código baseado em condições lógicas.

**Loop**

Estrutura que repete bloco de código enquanto condição específica for verdadeira.

**Recursão**

Técnica onde função chama a si mesma para resolver versões menores do mesmo problema.

**Exceção**

Evento que interrompe fluxo normal de execução do programa devido a erro ou condição especial.

### Gerenciamento de Memória

**Garbage Collection**

Processo automático de liberação de memória não mais referenciada pelo programa.

**Memory Leak**

Situação onde programa falha em liberar memória alocada, causando consumo crescente.

**Ponteiro**

Variável que armazena endereço de memória de outra variável.

**Referência**

Alias para variável existente que permite acesso indireto aos dados.

**Alocação Dinâmica**

Processo de reservar memória durante execução do programa conforme necessário.

## G.5 Acrônimos e Abreviações

### Algoritmos e Estruturas de Dados

**ADT** - Abstract Data Type (Tipo Abstrato de Dados)

Especificação matemática de tipo de dados definido por comportamento, não implementação.

**AVL** - Adelson-Velsky and Landis

Tipo de árvore binária de busca auto-balanceada com diferença de altura limitada.

**BFS** - Breadth-First Search (Busca em Largura)

Algoritmo de travessia de grafo que explora vizinhos antes de avançar em profundidade.

**BST** - Binary Search Tree (Árvore Binária de Busca)

Estrutura de dados hierárquica que mantém elementos em ordem para busca eficiente.

**DAG** - Directed Acyclic Graph (Grafo Acíclico Dirigido)

Grafo direcionado sem ciclos, usado em ordenação topológica e scheduling.

**DFS** - Depth-First Search (Busca em Profundidade)

Algoritmo de travessia que explora caminho completo antes de retroceder.

**DP** - Dynamic Programming (Programação Dinâmica)

Técnica de otimização que resolve subproblemas sobrepostos armazenando resultados.

**FIFO** - First In, First Out (Primeiro a Entrar, Primeiro a Sair)

Disciplina de acesso usada em filas onde primeiro elemento inserido é primeiro removido.

**LCA** - Lowest Common Ancestor (Ancestral Comum Mais Baixo)

Nó mais profundo que é ancestral comum de dois nós em árvore.

**LIFO** - Last In, First Out (Último a Entrar, Primeiro a Sair)

Disciplina de acesso usada em pilhas onde último elemento inserido é primeiro removido.

**LIS** - Longest Increasing Subsequence (Subsequência Crescente Mais Longa)

Problema clássico de encontrar maior subsequência em ordem crescente.

**LCS** - Longest Common Subsequence (Subsequência Comum Mais Longa)

Problema de encontrar maior subsequência comum entre duas sequências.

**MST** - Minimum Spanning Tree (Árvore Geradora Mínima)

Subgrafo conexo e acíclico que conecta todos vértices com peso mínimo total.

**RMQ** - Range Minimum Query (Consulta de Mínimo em Intervalo)

Problema de encontrar elemento mínimo em intervalo específico de array.

### Teoria da Computação

**CFG** - Context-Free Grammar (Gramática Livre de Contexto)

Tipo de gramática formal usada para definir linguagens de programação.

**FSA** - Finite State Automaton (Autômato Finito)

Modelo computacional com número finito de estados para reconhecimento de linguagens.

**NFA** - Nondeterministic Finite Automaton (Autômato Finito Não-Determinístico)

Autômato que pode ter múltiplas transições para mesmo símbolo de entrada.

**DFA** - Deterministic Finite Automaton (Autômato Finito Determinístico)

Autômato com exatamente uma transição para cada símbolo em cada estado.

**PDA** - Pushdown Automaton (Autômato com Pilha)

Autômato finito estendido com pilha para reconhecer linguagens livres de contexto.

**TM** - Turing Machine (Máquina de Turing)

Modelo abstrato de computação que define limites teóricos da computabilidade.

### Complexidade Computacional

**P** - Polynomial Time (Tempo Polinomial)

Classe de problemas decidíveis em tempo polinomial por máquina determinística.

**NP** - Nondeterministic Polynomial Time (Tempo Polinomial Não-Determinístico)

Classe de problemas verificáveis em tempo polinomial.

**NP-Complete** - NP-Completo

Problemas NP que são pelo menos tão difíceis quanto qualquer problema em NP.

**NP-Hard** - NP-Difícil

Problemas pelo menos tão difíceis quanto problemas NP-completos, mas não necessariamente em NP.

**PSPACE** - Polynomial Space (Espaço Polinomial)

Classe de problemas decidíveis usando espaço polinomial.

**EXP** - Exponential Time (Tempo Exponencial)

Classe de problemas decidíveis em tempo exponencial.

### Estruturas de Dados Avançadas

**B-Tree** - Árvore B

Estrutura de dados auto-balanceada otimizada para sistemas com acesso lento (discos).

**LSM** - Log-Structured Merge-tree (Árvore de Merge Estruturada em Log)

Estrutura otimizada para escritas frequentes em sistemas de armazenamento.

**RB-Tree** - Red-Black Tree (Árvore Rubro-Negra)

Árvore binária de busca balanceada com propriedades de coloração para garantir balanceamento.

**Trie** - Prefix Tree (Árvore de Prefixos)

Estrutura de dados tipo árvore usada para armazenamento eficiente de strings.

**UFO** - Union-Find/Disjoint Set (Estrutura Union-Find)

Estrutura para manter coleção de conjuntos disjuntos com operações de união e busca.

### Programação e Desenvolvimento

**API** - Application Programming Interface (Interface de Programação de Aplicações)

Conjunto de definições e protocolos para construir e integrar software.

**IDE** - Integrated Development Environment (Ambiente de Desenvolvimento Integrado)

Software que fornece ferramentas abrangentes para desenvolvimento de software.

**OOP** - Object-Oriented Programming (Programação Orientada a Objetos)

Paradigma baseado em conceito de objetos que contêm dados e código.

**RAII** - Resource Acquisition Is Initialization (Aquisição de Recurso é Inicialização)

Técnica de programação para gerenciamento automático de recursos.

**SOLID** - Single Responsibility, Open-Closed, Liskov Substitution, Interface Segregation, Dependency Inversion

Princípios de design orientado a objetos para código maintível.

**TDD** - Test-Driven Development (Desenvolvimento Orientado por Testes)

Metodologia onde testes são escritos antes da implementação do código.

### Matemática e Lógica

**GCD** - Greatest Common Divisor (Máximo Divisor Comum)

Maior inteiro positivo que divide dois ou mais números inteiros.

**LCM** - Least Common Multiple (Mínimo Múltiplo Comum)

Menor inteiro positivo que é múltiplo de dois ou mais números.

**CNF** - Conjunctive Normal Form (Forma Normal Conjuntiva)

Forma padrão de fórmula lógica como conjunção de disjunções.

**DNF** - Disjunctive Normal Form (Forma Normal Disjuntiva)

Forma padrão de fórmula lógica como disjunção de conjunções.

**SAT** - Boolean Satisfiability Problem (Problema de Satisfatibilidade Booleana)

Problema de determinar se existe interpretação que torna fórmula booleana verdadeira.
