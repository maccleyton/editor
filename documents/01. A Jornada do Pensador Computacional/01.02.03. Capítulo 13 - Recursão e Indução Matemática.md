## 13. Recursão e Indução Matemática

---

## 13.1 Conceito de Recursão

- Recursão é uma técnica de programação e matemática onde uma função chama a si mesma para resolver subproblemas menores do problema original.
- O problema é reduzido successivamente até atingir um caso trivial (caso base) que pode ser resolvido diretamente.
- Usa-se para problemas naturalmente definidos em termos de partes menores, como cálculo de fatorial, Fibonacci, busca em árvores.

---

## 13.2 Casos Base e Casos Recursivos

- **Caso base:** condição que termina a recursão, quando o problema é suficientemente simples para ser resolvido sem nova chamada.
- **Caso recursivo:** parte da função que chama ela mesma para um problema menor.

Exemplo: função fatorial

```python
def fatorial(n):
    if n == 0:
        return 1  *# caso base*
    else:
        return n * fatorial(n-1)  *# caso recursivo*
```

---

## 13.3 Tipos de Recursão

### 13.3.1 Recursão Direta

- Quando a função chama diretamente a si mesma.

Exemplo clássico do fatorial acima.

### 13.3.2 Recursão Indireta

- Quando uma função A chama outra função B, que por sua vez chama A novamente, criando um ciclo indireto.

Exemplo:

```python
def funcA(n):
    if n > 0:
        funcB(n-1)

def funcB(n):
    if n > 0:
        funcA(n//2)
```

### 13.3.3 Recursão de Cauda

- A chamada recursiva é a última operação que a função executa antes de retornar.
- Permite otimização pelo compilador/interpréte para evitar empilhamento excessivo (tail call optimization).

Exemplo de recursão de cauda para fatorial:

```python
def fatorial_tail(n, acc=1):
    if n == 0:
        return acc
    else:
        return fatorial_tail(n-1, acc * n)
```

## 13.4 Indução Matemática

---

### 13.4.1 Princípio da Indução

- Método matemático para demonstrar que uma propriedade $P(n)$ é verdadeira para todos os números naturais $n \geq n_0$.
- Composto de dois passos:
    1. **Base da indução:** verifica que $P(n_0)$ é verdadeira.
    2. **Passo indutivo:** prova que, se $P(k)$ é verdadeira para algum $k \geq n_0$, então $P(k+1)$ também é verdadeira.
- É como efeito dominó: se o primeiro cai e cada um derruba o próximo, todos cairão.

---

### 13.4.2 Indução Forte

- Variante onde, para provar $P(k+1)$, assume-se que $P(n_0), P(n_0+1), \ldots, P(k)$ são todas verdadeiras.
- Útil quando $P(k+1)$ depende de vários casos anteriores, não apenas do imediato.

---

### 13.4.3 Prova por Indução

- Estrutura formal para demonstrar propriedades.

Exemplo clássico:

Prove que para todo $n \geq 1$,

$1 + 2 + \cdots + n = \frac{n(n+1)}{2}$

- Base: para $n=1$,

$1 = \frac{1 \times (1+1)}{2} = 1$

- Passo indutivo: suponha verdadeiro para $n = k$,

$1 + 2 + \cdots + k = \frac{k(k+1)}{2}$

Mostre para $n = k+1$:

$\begin{aligned}1 + 2 + \cdots + k + (k+1) &= \frac{k(k+1)}{2} + (k+1) \\
&= \frac{k(k+1) + 2(k+1)}{2} \\
&= \frac{(k+1)(k+2)}{2}\end{aligned}$

Logo, a fórmula é verdadeira para $k+1$.

## 13.5 Relações de Recorrência

---

### 13.5.1 Definição

- Relação de recorrência é uma equação que define uma sequência de valores onde cada termo é definido em função de termos anteriores.
- Formalmente, uma sequência $(a_n)$ satisfaz uma relação de recorrência se para algum $k$, cada termo ana_nan é uma função dos kkk termos anteriores:
    
    $a_n = f(a_{n-1}, a_{n-2}, ..., a_{n-k})$
    
- Exemplo clássico: sequência de Fibonacci
    
    $F_n = F_{n-1} + F_{n-2}, \quad \text{com } F_1 = 1, F_2 = 1$
    

---

### 13.5.2 Métodos de Resolução

- **Substituição (ou método do palpites):** chutar uma forma para a solução e provar por indução.
- **Expansão:** expandir os termos da recorrência para identificar um padrão.
- **Relação característica:** para recorrências lineares homogêneas, transforma-se a recorrência numa equação algébrica para encontrar uma solução fechada.
- **Métodos específicos:** teorema mestre, transformadas de generating functions, entre outros.

---

### 13.5.3 Teorema Mestre

- Método padrão para resolver relações de recorrência em algoritmos recursivos do tipo:
    
    $T(n) = a \cdot T\left(\frac{n}{b}\right) + f(n)$
    
    onde $a \geq 1$ e $b > 1$.
    
- O teorema dá a complexidade assintótica de $T(n)$ baseado na comparação entre $f(n)$ e $n^{\log_b a}$:
    - Se $f(n) = O(n^{\log_b a - \epsilon})$ para algum $\epsilon > 0$, então
        
        $T(n) = \Theta(n^{\log_b a})$
        
    - Se $f(n) = \Theta(n^{\log_b a} \cdot \log^k n)$ para algum $k \geq 0$, então
        
        $T(n) = \Theta(n^{\log_b a} \cdot \log^{k+1} n)$
        
    - Se $f(n) = \Omega(n^{\log_b a + \epsilon})$ para algum $\epsilon > 0$, e $af(n/b) \leq c f(n)$ para algum $c < 1$ e para nnn suficientemente grande, então
        
        $T(n) = \Theta(f(n))$
        
- Aplicação comum para análise de algoritmos "dividir para conquistar", como Merge Sort.

### 13.6.1 Fibonacci

- Sequência onde cada termo é soma dos dois anteriores: $F_0=0, F_1=1, F_n=F_{n-1}+F_{n-2}$.
- Aplicações: modelagem de problemas recursivos, algoritmos de programação dinâmica, análise da Proporção Áurea.
- Implementação recursiva (não otimizada):

```python
def fibonacci(n):
    if n == 0: return 0
    elif n == 1: return 1
    else: return fibonacci(n-1) + fibonacci(n-2)
```

- Implementação iterativa (mais eficiente):

```python
def fibonacci_iter(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
```

### 13.6.2 Torres de Hanói

- Problema clássico onde se movem discos entre três pinos respeitando regras.
- Número mínimo de movimentos: $2^n - 1$, para $n$ discos.
- Solução recursiva:

```python
def hanoi(n, origem, destino, auxiliar):
    if n == 1:
        print(f"Mova disco de {origem} para {destino}")
    else:
        hanoi(n-1, origem, auxiliar, destino)
        print(f"Mova disco de {origem} para {destino}")
        hanoi(n-1, auxiliar, destino, origem)
```

### 13.6.3 Busca Binária

- Busca eficiente em listas ordenadas, dividindo o espaço de busca pela metade a cada passo.
- Complexidade: $O(\log n)$

Implementação iterativa:

```python
def busca_binaria(arr, x):
    left, right = 0, len(arr)-1
    while left <= right:
        mid = (left + right) // 2
        if arr[mid] == x:
            return mid
        elif arr[mid] < x:
            left = mid + 1
        else:
            right = mid - 1
    return -1
```

### 13.6.4 Quicksort e Mergesort

- Algoritmos eficientes de ordenação baseados em divide e conquista.

**Quicksort:**

- Escolhe pivô, particiona elementos menores e maiores, ordena recursivamente as partições.
- Médio e melhor caso: $O(n \log n)$, pior caso: $O(n^2)$.

```python
def quicksort(arr):
    if len(arr) <= 1:
        return arr
    pivo = arr[len(arr)//2]
    menores = [x for x in arr if x < pivo]
    iguais = [x for x in arr if x == pivo]
    maiores = [x for x in arr if x > pivo]
    return quicksort(menores) + iguais + quicksort(maiores)
```

**Mergesort:**

- Divide a lista em partes, ordena recursivamente e mescla ordenado.
- Complexidade garantida $O(n \log n)$.

```python
def mergesort(arr):
    if len(arr) <= 1:
        return arr
    meio = len(arr)//2
    esquerda = mergesort(arr[:meio])
    direita = mergesort(arr[meio:])
    return merge(esquerda, direita)

def merge(left, right):
    resultado = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] < right[j]:
            resultado.append(left[i])
            i += 1
        else:
            resultado.append(right[j])
            j += 1
    resultado.extend(left[i:])
    resultado.extend(right[j:])
    return resultado
```
