**Função:** Gerenciar cadastro de livros, usuários, empréstimos, devoluções.

4. Métodos para empréstimo e devolução ajustam disponibilidade.

**Exemplo simplificado em Python:**

```python
class Livro:
    def __init__(self, titulo):
        self.titulo = titulo
        self.disponivel = True

class Usuario:
    def __init__(self, nome):
        self.nome = nome
        self.livros_emprestados = []

class Biblioteca:
    def __init__(self):
        self.livros = []
        self.usuarios = []

    def cadastrar_livro(self, titulo):
        self.livros.append(Livro(titulo))

    def cadastrar_usuario(self, nome):
        self.usuarios.append(Usuario(nome))

    def emprestar(self, titulo, nome_usuario):
        livro = next((l for l in self.livros if l.titulo == titulo and l.disponivel), None)
        usuario = next((u for u in self.usuarios if u.nome == nome_usuario), None)
        if livro and usuario:
            livro.disponivel = False
            usuario.livros_emprestados.append(livro)
            print(f"Livro '{titulo}' emprestado para {nome_usuario}")
        else:
            print("Empréstimo não autorizado")

*# Exemplo de uso*
b = Biblioteca()
b.cadastrar_livro("1984")
b.cadastrar_usuario("Alice")
b.emprestar("1984", "Alice")
```

**Exemplo guiado em Python:**

```python
def converter_numero(num_str, base_origem, base_destino):
    try:
        decimal = int(num_str, base_origem)
        if base_destino == 10:
            return str(decimal)
        elif base_destino == 2:
            return bin(decimal)[2:]
        elif base_destino == 8:
            return oct(decimal)[2:]
        elif base_destino == 16:
            return hex(decimal)[2:].upper()
        else:
            return "Base destino não suportada"
    except ValueError:
        return "Número inválido na base origem"
```

### 31.2.1 Sistema de Busca com Indexação

**Função:** Implementar um sistema que realiza buscas rápidas em coleções de texto usando indexação simples.

**Passo a passo:**

1. Receber um conjunto de documentos ou frases.
2. Criar índice invertido que mapeará palavras para as listas de documentos em que aparecem.
3. Implementar função para consultar termos e retornar documentos relevantes.
4. Tratar consultas simples e múltiplas.

**Exemplo simples em Python:**

```python
class Indexador:
    def __init__(self):
        self.indice_invertido = {}

    def indexar(self, documentos):
        for i, doc in enumerate(documentos):
            for palavra in doc.lower().split():
                if palavra not in self.indice_invertido:
                    self.indice_invertido[palavra] = set()
                self.indice_invertido[palavra].add(i)

    def buscar(self, termo):
        return self.indice_invertido.get(termo.lower(), set())

*# Exemplo*
docs = ["Gato e cachorro", "Cachorro e pássaro", "Gato no telhado"]
idx = Indexador()
idx.indexar(docs)
print(idx.buscar("cachorro"))  *# Saída: {0, 1}*
print(idx.buscar("gato"))      *# Saída: {0, 2}*
```

### 31.2.4 Sistema de Criptografia RSA

**Função:** Gerar chaves, cifrar e decifrar mensagens usando RSA.

**Passo a passo:**

1. Gerar números primos grandes (simulados com pequenos para exemplo).
2. Calcular módulo nnn e totiente ϕ\phiϕ.
3. Escolher expoente público eee e calcular privado ddd (inverso modular).
4. Implementar funções para cifrar e decifrar.

**Exemplo simplificado:**

```python
def gcd(a, b):
    while b:
        a, b = b, a % b
    return a

def modinv(a, m):
    *# Algoritmo de Euclides estendido*
    m0, x0, x1 = m, 0, 1
    while a > 1:
        q = a // m
        a, m = m, a % m
        x0, x1 = x1 - q * x0, x0
    return x1 + m0 if x1 < 0 else x1

p = 61
q = 53
n = p * q
phi = (p-1)*(q-1)
e = 17  *# primo com phi*
d = modinv(e, phi)

def cifrar(m):
    return pow(m, e, n)

def decifrar(c):
    return pow(c, d, n)
```

### 31.2.6 Gerador de Fractais

**Função:** Criar imagens fractais usando iteração matemática (ex.: conjunto de Mandelbrot).

**Passo a passo:**

1. Definir função iterativa para ponto no plano complexo.
2. Iterar e verificar divergência para colorir pixels.
3. Gerar imagem usando biblioteca (ex.: PIL, matplotlib).

**Exemplo simplificado com matplotlib:**

```python
import numpy as np
import matplotlib.pyplot as plt

def mandelbrot(h, w, max_iter=100):
    x = np.linspace(-2, 1, w)
    y = np.linspace(-1.5, 1.5, h)
    c = x + y[:, None]*1j
    z = np.zeros_like(c)
    div = np.zeros(z.shape, dtype=int)
    mask = np.ones(z.shape, bool)

    for i in range(max_iter):
        z[mask] = z[mask]**2 + c[mask]
        mask_new = abs(z) < 2
        div[mask & ~mask_new] = i
        mask = mask & mask_new
    return div

plt.imshow(mandelbrot(500, 500), cmap='inferno')
plt.axis('off')
plt.show()
```

### 31.3.3 Sistema de Roteamento GPS

**Objetivo:** Calcular rotas ótimas em grafos com pesos, usando algoritmos como Dijkstra ou A*.

**Passo a passo:**

1. Representar mapa como grafo com nós e arestas ponderadas.
2. Implementar algoritmo de rota (exemplo Dijkstra).
3. Receber entrada para origem e destino.
4. Exibir caminho encontrado e custo total.

**Exemplo simples Dijkstra:**

```python
import heapq

def dijkstra(grafo, inicio, fim):
    dist = {no: float('inf') for no in grafo}
    dist[inicio] = 0
    fila = [(0, inicio)]
    caminho = {}

    while fila:
        custo_atual, no = heapq.heappop(fila)
        if no == fim:
            break
        for vizinho, peso in grafo[no]:
            nova_dist = custo_atual + peso
            if nova_dist < dist[vizinho]:
                dist[vizinho] = nova_dist
                caminho[vizinho] = no
                heapq.heappush(fila, (nova_dist, vizinho))

    rota = []
    atual = fim
    while atual != inicio:
        rota.append(atual)
        atual = caminho[atual]
    rota.append(inicio)
    rota.reverse()
    return rota, dist[fim]

grafo = {
    'A': [('B', 1), ('C', 4)],
    'B': [('C', 2), ('D', 5)],
    'C': [('D', 1)],
    'D': []
}

rota, custo = dijkstra(grafo, 'A', 'D')
print("Rota:", rota)
print("Custo total:", custo)
```

### 31.4.1 Algoritmo Genético para Otimização

**Objetivo:** Implementar algoritmo genético para otimizar soluções num problema dado.

**Passo a passo:**

1. Inicializar população aleatória de indivíduos (listas binárias ou numerais).
2. Avaliar aptidão (função objetivo).
3. Selecionar os melhores indivíduos para reprodução.
4. Realizar crossover (recombinação).
5. Introduzir mutações.
6. Repetir ciclo até convergência ou limite de gerações.

**Exemplo básico em Python:**

```python
import random

def initialize_population(size, individual_length):
    return [[random.randint(0, 1) for _ in range(individual_length)] for _ in range(size)]

def fitness(individual):
    *# Exemplo: soma dos bits*
    return sum(individual)

def crossover(parent1, parent2):
    point = random.randint(1, len(parent1) - 1)
    return parent1[:point] + parent2[point:]

def mutate(individual, mutation_rate=0.01):
    return [bit ^ (random.random() < mutation_rate) for bit in individual]

def genetic_algorithm(pop_size, individual_length, generations):
    population = initialize_population(pop_size, individual_length)
    for gen in range(generations):
        population = sorted(population, key=fitness, reverse=True)
        parents = population[:pop_size//5]
        children = []
        while len(children) < pop_size - len(parents):
            p1, p2 = random.sample(parents, 2)
            child = mutate(crossover(p1, p2))
            children.append(child)
        population = parents + children
        print(f"Geração {gen}: Melhor aptidão = {fitness(population[0])}")

    return population[0]

best = genetic_algorithm(20, 10, 50)
print("Melhor indivíduo encontrado:", best)
```
