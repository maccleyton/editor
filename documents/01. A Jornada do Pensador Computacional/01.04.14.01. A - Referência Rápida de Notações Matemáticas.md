## A.1 Teoria dos Conjuntos

### Notações Básicas e Operações

**Definições Fundamentais**

```bash
Conjunto: Coleção de elementos distintos
Notação: A = {1, 2, 3, 4, 5}
Conjunto vazio: ∅ ou {}
Universo: U (conjunto de todos elementos considerados)

Pertinência:
x ∈ A    (x pertence a A)
x ∉ A    (x não pertence a A)

Cardinalidade:
|A|      (número de elementos em A)
|{1,2,3}| = 3
```

**Relações entre Conjuntos**

```bash
Subconjunto:
A ⊆ B    (A é subconjunto de B: todo elemento de A está em B)
A ⊂ B    (A é subconjunto próprio de B: A ⊆ B e A ≠ B)

Igualdade:
A = B    (A e B têm exatamente os mesmos elementos)

Exemplos:
{1, 2} ⊆ {1, 2, 3, 4}
{1, 2} ⊂ {1, 2, 3, 4}
{1, 2} = {2, 1}    (ordem não importa)
```

**Operações com Conjuntos**

```bash
União:
A ∪ B = {x : x ∈ A ou x ∈ B}
{1, 2} ∪ {2, 3} = {1, 2, 3}

Interseção:
A ∩ B = {x : x ∈ A e x ∈ B}
{1, 2, 3} ∩ {2, 3, 4} = {2, 3}

Diferença:
A \ B = {x : x ∈ A e x ∉ B}
{1, 2, 3} \ {2, 4} = {1, 3}

Complemento:
A^c = U \ A = {x ∈ U : x ∉ A}

Diferença Simétrica:
A △ B = (A \ B) ∪ (B \ A)
{1, 2, 3} △ {2, 3, 4} = {1, 4}
```

**Produto Cartesiano**

```bash
A × B = {(a, b) : a ∈ A e b ∈ B}

Exemplo:
{1, 2} × {a, b} = {(1,a), (1,b), (2,a), (2,b)}

Aplicação em Programação:
- Representação de coordenadas
- Chaves compostas em bancos de dados
- Estados em máquinas de estado
```

**Leis Fundamentais**

```bash
Leis de De Morgan:
(A ∪ B)^c = A^c ∩ B^c
(A ∩ B)^c = A^c ∪ B^c

Leis Distributivas:
A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)
A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)

Leis de Idempotência:
A ∪ A = A
A ∩ A = A

Leis de Absorção:
A ∪ (A ∩ B) = A
A ∩ (A ∪ B) = A
```

**Aplicações Computacionais**

```bash
Estruturas de Dados:
- Set/HashSet: implementação direta de conjuntos
- Operações: union(), intersection(), difference()

Algoritmos:
- Filtros: implementação de ∩ e \
- Joins em bancos: produto cartesiano filtrado
- Análise de dependências: relações de subconjunto

Exemplo em Python:
set_a = {1, 2, 3, 4}
set_b = {3, 4, 5, 6}
union = set_a | set_b          # {1, 2, 3, 4, 5, 6}
intersection = set_a & set_b   # {3, 4}
difference = set_a - set_b     # {1, 2}
```

## A.2 Lógica Proposicional

### Proposições e Operadores Lógicos

**Proposições Básicas**

```bash
Proposição: Declaração que é verdadeira ou falsa
Notação: p, q, r, s, ...
Valores de verdade: V (verdadeiro), F (falso) ou 1, 0

Exemplos:
p: "O número 7 é primo"           (V)
q: "2 + 2 = 5"                    (F)
r: "x > 0"                        (depende de x)
```

**Conectivos Lógicos**

```bash
Negação:
¬p ou ~p (não p)
Tabela verdade:
p  | ¬p
V  | F
F  | V

Conjunção:
p ∧ q (p e q)
Tabela verdade:
p | q | p∧q
V | V | V
V | F | F
F | V | F
F | F | F

Disjunção:
p ∨ q (p ou q)
Tabela verdade:
p | q | p∨q
V | V | V
V | F | V
F | V | V
F | F | F

Implicação:
p → q (se p então q)
Tabela verdade:
p | q | p→q
V | V | V
V | F | F
F | V | V
F | F | V

Equivalência:
p ↔ q (p se e somente se q)
Tabela verdade:
p | q | p↔q
V | V | V
V | F | F
F | V | F
F | F | V
```

**Disjunção Exclusiva**

```bash
p ⊕ q (p ou exclusivo q)
Tabela verdade:
p | q | p⊕q
V | V | F
V | F | V
F | V | V
F | F | F

Aplicação: operação XOR em programação
```

**Precedência de Operadores**

```bash
Ordem de precedência (maior para menor):
1. ¬ (negação)
2. ∧ (conjunção)
3. ∨ (disjunção)
4. → (implicação)
5. ↔ (equivalência)

Exemplo:
¬p ∧ q ∨ r → s
= ((¬p) ∧ q) ∨ r → s
= (((¬p) ∧ q) ∨ r) → s
```

**Leis da Lógica Proposicional**

```bash
Leis de De Morgan:
¬(p ∧ q) ≡ ¬p ∨ ¬q
¬(p ∨ q) ≡ ¬p ∧ ¬q

Leis Distributivas:
p ∧ (q ∨ r) ≡ (p ∧ q) ∨ (p ∧ r)
p ∨ (q ∧ r) ≡ (p ∨ q) ∧ (p ∨ r)

Leis de Idempotência:
p ∧ p ≡ p
p ∨ p ≡ p

Leis de Absorção:
p ∧ (p ∨ q) ≡ p
p ∨ (p ∧ q) ≡ p

Dupla Negação:
¬¬p ≡ p

Implicação Material:
p → q ≡ ¬p ∨ q
```

**Formas Normais**

```bash
Forma Normal Conjuntiva (CNF):
Conjunção de disjunções
Exemplo: (p ∨ q) ∧ (¬p ∨ r) ∧ (q ∨ ¬r)

Forma Normal Disjuntiva (DNF):
Disjunção de conjunções
Exemplo: (p ∧ q) ∨ (¬p ∧ r) ∨ (q ∧ ¬r)

Aplicação: SAT solving, otimização de circuitos
```

**Quantificadores**

```bash
Quantificador Universal:
∀x P(x) (para todo x, P(x) é verdadeiro)

Quantificador Existencial:
∃x P(x) (existe x tal que P(x) é verdadeiro)

Negação de Quantificadores:
¬∀x P(x) ≡ ∃x ¬P(x)
¬∃x P(x) ≡ ∀x ¬P(x)

Exemplo:
∀x (x > 0 → x² > 0)
∃x (x² = 4)
```

**Aplicações em Programação**

```bash
Estruturas Condicionais:
if (condition1 && condition2)     // ∧
if (condition1 || condition2)     // ∨
if (!condition)                   // ¬

Validação de Dados:
age >= 18 && hasLicense && !isSuspended

Controle de Fluxo:
while (hasData && !errorOccurred)

SQL WHERE clauses:
WHERE age > 18 AND (city = 'NYC' OR state = 'CA')

Algoritmos de Busca:
if (target == current) return found;
if (target < current && hasLeft) searchLeft();
```

## A.3 Notação Assintótica

### Análise de Complexidade de Algoritmos

**Notação Big O**

```bash
Definição:
f(n) = O(g(n)) se ∃c > 0, n₀ > 0 tal que
f(n) ≤ c·g(n) para todo n ≥ n₀

Significado: f cresce no máximo tão rápido quanto g
Uso: limite superior (pior caso)

Exemplos:
3n² + 2n + 1 = O(n²)
n log n + 5n = O(n log n)
2^n + n³ = O(2^n)
```

**Notação Big Omega**

```bash
Definição:
f(n) = Ω(g(n)) se ∃c > 0, n₀ > 0 tal que
f(n) ≥ c·g(n) para todo n ≥ n₀

Significado: f cresce pelo menos tão rápido quanto g
Uso: limite inferior (melhor caso)

Exemplos:
n² + 3n = Ω(n²)
n log n = Ω(n)
```

**Notação Big Theta**

```bash
Definição:
f(n) = Θ(g(n)) se f(n) = O(g(n)) e f(n) = Ω(g(n))

Significado: f e g têm a mesma taxa de crescimento
Uso: crescimento exato

Exemplo:
3n² + 2n + 1 = Θ(n²)
```

**Notação Little O**

```bash
Definição:
f(n) = o(g(n)) se lim(n→∞) f(n)/g(n) = 0

Significado: f cresce estritamente mais devagar que g

Exemplo:
n = o(n²)
log n = o(n)
```

**Notação Little Omega**

```bash
Definição:
f(n) = ω(g(n)) se lim(n→∞) f(n)/g(n) = ∞

Significado: f cresce estritamente mais rápido que g

Exemplo:
n² = ω(n)
2^n = ω(n^k) para qualquer k
```

**Hierarquia de Complexidades**

```bash
Do menor para o maior crescimento:

O(1)        - Constante
O(log n)    - Logarítmica
O(n)        - Linear
O(n log n)  - Linearítmica
O(n²)       - Quadrática
O(n³)       - Cúbica
O(2^n)      - Exponencial
O(n!)       - Fatorial

Comparação para n = 1000:
O(1):        1
O(log n):    ≈10
O(n):        1,000
O(n log n):  ≈10,000
O(n²):       1,000,000
O(2^n):      2^1000 (inviável)
```

**Regras de Cálculo**

```bash
Soma:
O(f(n)) + O(g(n)) = O(max(f(n), g(n)))
Exemplo: O(n) + O(n²) = O(n²)

Produto:
O(f(n)) · O(g(n)) = O(f(n) · g(n))
Exemplo: O(n) · O(log n) = O(n log n)

Composição:
f(n) = O(g(n)) ⟹ h(f(n)) = O(h(g(n)))
se h é monotônica

Constantes:
O(c · f(n)) = O(f(n)) para c > 0
```

**Complexidade de Espaço**

```bash
Notação similar para uso de memória:

O(1)     - Espaço constante
O(n)     - Espaço linear
O(n²)    - Espaço quadrático

Exemplo:
quicksort: O(log n) espaço (recursão)
mergesort: O(n) espaço (array auxiliar)
```

**Análise Amortizada**

```bash
Complexidade média sobre sequência de operações

Métodos:
1. Método Agregado
2. Método do Contador
3. Método do Potencial

Exemplo: Dynamic Array (ArrayList)
- Inserção simples: O(1)
- Inserção com resize: O(n)
- Inserção amortizada: O(1)
```

**Aplicações Práticas**

```bash
Algoritmos de Ordenação:
- Bubble Sort: O(n²) tempo, O(1) espaço
- Merge Sort: O(n log n) tempo, O(n) espaço
- Quick Sort: O(n log n) médio, O(n²) pior caso

Estruturas de Dados:
- Array: O(1) acesso, O(n) busca
- Hash Table: O(1) médio, O(n) pior caso
- Binary Search Tree: O(log n) médio, O(n) pior

Busca:
- Linear Search: O(n)
- Binary Search: O(log n)
- Hash Lookup: O(1) médio
```

## A.4 Probabilidade e Estatística

### Conceitos Fundamentais

**Experimentos e Eventos**

```bash
Experimento: Processo que produz resultado
Espaço Amostral (Ω): Conjunto de todos resultados possíveis
Evento: Subconjunto do espaço amostral

Exemplo: Lançamento de dado
Ω = {1, 2, 3, 4, 5, 6}
A = "número par" = {2, 4, 6}
B = "número > 4" = {5, 6}
```

**Probabilidade Clássica**

```bash
Para eventos equiprováveis:
P(A) = |A| / |Ω|

Axiomas de Kolmogorov:
1. P(A) ≥ 0 para todo evento A
2. P(Ω) = 1
3. P(A ∪ B) = P(A) + P(B) se A ∩ B = ∅

Propriedades:
P(∅) = 0
P(A^c) = 1 - P(A)
P(A ∪ B) = P(A) + P(B) - P(A ∩ B)
```

**Probabilidade Condicional**

```bash
P(A|B) = P(A ∩ B) / P(B), se P(B) > 0

Interpretação: probabilidade de A dado que B ocorreu

Independência:
A e B são independentes se P(A|B) = P(A)
Equivalentemente: P(A ∩ B) = P(A) · P(B)

Exemplo:
P(Chover hoje | Choveu ontem) vs P(Chover hoje)
```

**Teorema de Bayes**

```bash
P(A|B) = P(B|A) · P(A) / P(B)

Forma expandida:
P(A|B) = P(B|A) · P(A) / [P(B|A)·P(A) + P(B|A^c)·P(A^c)]

Aplicação: Classificação, Diagnóstico, Machine Learning

Exemplo: Teste médico
P(Doença|Teste+) = P(Teste+|Doença) · P(Doença) / P(Teste+)
```

**Variáveis Aleatórias Discretas**

```bash
Função de Probabilidade:
P(X = x) = probabilidade de X assumir valor x
∑ P(X = x) = 1 (sobre todos x possíveis)

Função de Distribuição:
F(x) = P(X ≤ x)

Valor Esperado:
E[X] = ∑ x · P(X = x)

Variância:
Var(X) = E[(X - E[X])²] = E[X²] - (E[X])²

Desvio Padrão:
σ = √Var(X)
```

**Distribuições Discretas Importantes**

```bash
Distribuição Bernoulli:
X ~ Ber(p)
P(X = 1) = p, P(X = 0) = 1-p
E[X] = p, Var(X) = p(1-p)

Distribuição Binomial:
X ~ Bin(n, p)
P(X = k) = C(n,k) · p^k · (1-p)^(n-k)
E[X] = np, Var(X) = np(1-p)

Distribuição Poisson:
X ~ Pois(λ)
P(X = k) = e^(-λ) · λ^k / k!
E[X] = λ, Var(X) = λ

Distribuição Geométrica:
X ~ Geom(p)
P(X = k) = (1-p)^(k-1) · p
E[X] = 1/p, Var(X) = (1-p)/p²
```

**Variáveis Aleatórias Contínuas**

```bash
Função Densidade de Probabilidade (fdp):
f(x) ≥ 0
∫_{-∞}^{∞} f(x) dx = 1
P(a ≤ X ≤ b) = ∫_a^b f(x) dx

Função de Distribuição:
F(x) = P(X ≤ x) = ∫_{-∞}^x f(t) dt

Valor Esperado:
E[X] = ∫_{-∞}^{∞} x · f(x) dx

Variância:
Var(X) = ∫_{-∞}^{∞} (x - E[X])² · f(x) dx
```

**Distribuição Normal**

```bash
X ~ N(μ, σ²)
f(x) = (1/(σ√(2π))) · e^(-(x-μ)²/(2σ²))

Propriedades:
E[X] = μ
Var(X) = σ²

Distribuição Normal Padrão:
Z ~ N(0, 1)
Transformação: Z = (X - μ)/σ

Regra 68-95-99.7:
P(μ - σ ≤ X ≤ μ + σ) ≈ 0.68
P(μ - 2σ ≤ X ≤ μ + 2σ) ≈ 0.95
P(μ - 3σ ≤ X ≤ μ + 3σ) ≈ 0.997
```

**Aplicações Computacionais**

```bash
Algoritmos Randomizados:
- Quicksort randomizado: escolha aleatória de pivot
- Monte Carlo: simulação para aproximar soluções
- Algoritmos genéticos: mutação e seleção

Análise de Performance:
- Tempo esperado de algoritmos
- Probabilidade de pior caso
- Análise probabilística de estruturas de dados

Machine Learning:
- Naive Bayes: classificação probabilística
- Redes Bayesianas: modelagem de dependências
- Processamento de incerteza

Testing:
- Testes estatísticos A/B
- Análise de confiabilidade
- Simulação de carga

Criptografia:
- Geração de números aleatórios
- Análise de segurança probabilística
- Protocolos criptográficos
```

## A.5 Álgebra Linear

### Vetores e Operações Vetoriais

**Definições Básicas**

```bash
Vetor n-dimensional:
v = (v₁, v₂, ..., vₙ) ∈ ℝⁿ

Vetor coluna:
v = [v₁]
    [v₂]
    [⋮ ]
    [vₙ]

Vetor linha:
v = [v₁  v₂  ...  vₙ]

Vetor zero:
0 = (0, 0, ..., 0)
```

**Operações com Vetores**

```bash
Adição:
u + v = (u₁ + v₁, u₂ + v₂, ..., uₙ + vₙ)

Multiplicação por escalar:
αv = (αv₁, αv₂, ..., αvₙ)

Produto interno (dot product):
u · v = u₁v₁ + u₂v₂ + ... + uₙvₙ = ∑ᵢ uᵢvᵢ

Norma euclidiana:
‖v‖ = √(v · v) = √(v₁² + v₂² + ... + vₙ²)

Distância euclidiana:
d(u, v) = ‖u - v‖

Ângulo entre vetores:
cos θ = (u · v) / (‖u‖ ‖v‖)
```

**Independência Linear**

```bash
Vetores v₁, v₂, ..., vₖ são linearmente independentes se:
α₁v₁ + α₂v₂ + ... + αₖvₖ = 0 ⟹ α₁ = α₂ = ... = αₖ = 0

Base: conjunto linearmente independente que gera o espaço
Dimensão: número de vetores em uma base

Base canônica de ℝⁿ:
e₁ = (1, 0, 0, ..., 0)
e₂ = (0, 1, 0, ..., 0)
⋮
eₙ = (0, 0, 0, ..., 1)
```

**Matrizes**

```bash
Matriz m×n:
A = [a₁₁  a₁₂  ...  a₁ₙ]
    [a₂₁  a₂₂  ...  a₂ₙ]
    [ ⋮     ⋮    ⋱   ⋮  ]
    [aₘ₁  aₘ₂  ...  aₘₙ]

Matriz identidade:
I = [1  0  ...  0]
    [0  1  ...  0]
    [⋮   ⋮   ⋱   ⋮]
    [0  0  ...  1]

Matriz nula:
O = [0  0  ...  0]
    [0  0  ...  0]
    [⋮   ⋮   ⋱   ⋮]
    [0  0  ...  0]
```

**Operações com Matrizes**

```bash
Adição:
(A + B)ᵢⱼ = aᵢⱼ + bᵢⱼ

Multiplicação por escalar:
(αA)ᵢⱼ = α · aᵢⱼ

Multiplicação de matrizes:
(AB)ᵢⱼ = ∑ₖ aᵢₖ · bₖⱼ
Condição: número de colunas de A = número de linhas de B

Transposição:
(Aᵀ)ᵢⱼ = aⱼᵢ

Propriedades:
(A + B)ᵀ = Aᵀ + Bᵀ
(AB)ᵀ = BᵀAᵀ
(Aᵀ)ᵀ = A
```

**Determinante**

```bash
Para matriz 2×2:
det(A) = |a₁₁  a₁₂| = a₁₁a₂₂ - a₁₂a₂₁
         |a₂₁  a₂₂|

Para matriz 3×3 (regra de Sarrus):
det(A) = a₁₁a₂₂a₃₃ + a₁₂a₂₃a₃₁ + a₁₃a₂₁a₃₂
       - a₁₃a₂₂a₃₁ - a₁₁a₂₃a₃₂ - a₁₂a₂₁a₃₃

Propriedades:
det(AB) = det(A) · det(B)
det(Aᵀ) = det(A)
det(A⁻¹) = 1/det(A)
```

**Matriz Inversa**

```bash
A⁻¹ existe se e somente se det(A) ≠ 0

Propriedade fundamental:
A · A⁻¹ = A⁻¹ · A = I

Para matriz 2×2:
A⁻¹ = 1/det(A) · [ a₂₂  -a₁₂]
                  [-a₂₁   a₁₁]

Propriedades:
(A⁻¹)⁻¹ = A
(AB)⁻¹ = B⁻¹A⁻¹
(Aᵀ)⁻¹ = (A⁻¹)ᵀ
```

**Sistemas Lineares**

```bash
Sistema Ax = b onde:
A: matriz de coeficientes (m×n)
x: vetor de incógnitas (n×1)
b: vetor de termos independentes (m×1)

Solução única: A⁻¹ existe e x = A⁻¹b
Infinitas soluções: sistema consistente e det(A) = 0
Sem solução: sistema inconsistente

Métodos de resolução:
- Eliminação gaussiana: O(n³)
- Decomposição LU: O(n³)
- Método iterativo de Jacobi
- Método iterativo de Gauss-Seidel
```

**Autovalores e Autovetores**

```bash
Para matriz A (n×n):
Av = λv onde v ≠ 0

λ: autovalor
v: autovetor correspondente

Equação característica:
det(A - λI) = 0

Polinômio característico de grau n
Tem n autovalores (contando multiplicidade)

Diagonalização:
A = PDP⁻¹
onde D é diagonal (autovalores) e P tem autovetores como colunas
```

**Aplicações Computacionais**

```bash
Computação Gráfica:
- Transformações 2D/3D: rotação, translação, escala
- Projeções: perspectiva e ortogonal
- Câmeras virtuais: view matrix

Machine Learning:
- Principal Component Analysis (PCA)
- Linear regression: (XᵀX)⁻¹Xᵀy
- Neural networks: multiplicação matriz-vetor
- Support Vector Machines: kernel matrices

Processamento de Imagens:
- Filtros lineares: convolução como multiplicação
- Transformadas: Fourier, Wavelet
- Compressão: SVD (Singular Value Decomposition)

Redes e Grafos:
- Matriz de adjacência
- PageRank: autovetor dominante
- Centralidade: medidas baseadas em autovalores

Otimização:
- Métodos de gradiente: direções de descida
- Quadrados mínimos: minimização de ‖Ax - b‖²
- Programação linear: método simplex
```

## A.6 Cálculo

### Limites e Continuidade

**Definição de Limite**

```bash
lim[x→a] f(x) = L

Definição ε-δ:
∀ε > 0, ∃δ > 0 tal que
0 < |x - a| < δ ⟹ |f(x) - L| < ε

Limites laterais:
lim[x→a⁺] f(x) = L⁺ (limite pela direita)
lim[x→a⁻] f(x) = L⁻ (limite pela esquerda)

Limite existe ⟺ L⁺ = L⁻
```

**Propriedades de Limites**

```bash
Se lim[x→a] f(x) = L e lim[x→a] g(x) = M, então:

lim[x→a] [f(x) + g(x)] = L + M
lim[x→a] [f(x) · g(x)] = L · M
lim[x→a] [f(x) / g(x)] = L / M (se M ≠ 0)
lim[x→a] [c · f(x)] = c · L
lim[x→a] [f(x)]ⁿ = Lⁿ
```

**Limites Fundamentais**

```bash
lim[x→0] (sin x)/x = 1
lim[x→∞] (1 + 1/x)ˣ = e
lim[x→0] (eˣ - 1)/x = 1
lim[x→0] (ln(1 + x))/x = 1
lim[x→∞] (1 + a/x)ˣ = eᵃ
```

**Continuidade**

```bash
f é contínua em x = a se:
1. f(a) existe
2. lim[x→a] f(x) existe  
3. lim[x→a] f(x) = f(a)

Tipos de descontinuidade:
- Removível: limite existe mas f(a) ≠ lim[x→a] f(x)
- Salto: limites laterais existem mas são diferentes
- Infinita: pelo menos um limite lateral é infinito
```

### Derivadas

**Definição de Derivada**

```bash
f'(x) = lim[h→0] [f(x + h) - f(x)] / h

Notações:
f'(x) = df/dx = d/dx f(x) = Df(x)

Interpretação geométrica: inclinação da reta tangente
Interpretação física: taxa instantânea de variação
```

**Regras de Derivação**

```bash
Regra da constante:
d/dx [c] = 0

Regra da potência:
d/dx [xⁿ] = n·xⁿ⁻¹

Regra da soma:
d/dx [f(x) + g(x)] = f'(x) + g'(x)

Regra do produto:
d/dx [f(x)·g(x)] = f'(x)·g(x) + f(x)·g'(x)

Regra do quociente:
d/dx [f(x)/g(x)] = [f'(x)·g(x) - f(x)·g'(x)] / [g(x)]²

Regra da cadeia:
d/dx [f(g(x))] = f'(g(x))·g'(x)
```

**Derivadas de Funções Elementares**

```bash
d/dx [eˣ] = eˣ
d/dx [ln x] = 1/x
d/dx [sin x] = cos x
d/dx [cos x] = -sin x
d/dx [tan x] = sec²x
d/dx [aˣ] = aˣ ln a
d/dx [logₐ x] = 1/(x ln a)
```

**Aplicações da Derivada**

```bash
Análise de funções:
- Crescimento: f'(x) > 0 ⟹ f crescente
- Decrescimento: f'(x) < 0 ⟹ f decrescente
- Máximos/mínimos locais: f'(x) = 0

Derivada segunda:
f''(x) = d/dx [f'(x)]
- Concavidade: f''(x) > 0 ⟹ côncava para cima
- Pontos de inflexão: f''(x) = 0 e mudança de sinal

Otimização:
1. Encontrar pontos críticos: f'(x) = 0
2. Teste da derivada segunda: f''(x)
3. Análise dos extremos
```

### Integrais

**Integral Indefinida**

```bash
∫ f(x) dx = F(x) + C
onde F'(x) = f(x)

Propriedades:
∫ [f(x) + g(x)] dx = ∫ f(x) dx + ∫ g(x) dx
∫ c·f(x) dx = c·∫ f(x) dx
∫ F'(x) dx = F(x) + C
```

**Integrais Básicas**

```bash
∫ xⁿ dx = xⁿ⁺¹/(n+1) + C (n ≠ -1)
∫ 1/x dx = ln|x| + C
∫ eˣ dx = eˣ + C
∫ aˣ dx = aˣ/ln a + C
∫ sin x dx = -cos x + C
∫ cos x dx = sin x + C
∫ sec²x dx = tan x + C
∫ 1/(1+x²) dx = arctan x + C
∫ 1/√(1-x²) dx = arcsin x + C
```

**Técnicas de Integração**

```bash
Substituição:
∫ f(g(x))·g'(x) dx = ∫ f(u) du onde u = g(x)

Integração por partes:
∫ u dv = uv - ∫ v du

Frações parciais:
Para funções racionais P(x)/Q(x)

Substituições trigonométricas:
√(a² - x²): x = a sin θ
√(a² + x²): x = a tan θ  
√(x² - a²): x = a sec θ
```

**Integral Definida**

```bash
∫ₐᵇ f(x) dx = lim[n→∞] Σᵢ₌₁ⁿ f(xᵢ)Δx

Teorema Fundamental do Cálculo:
∫ₐᵇ f(x) dx = F(b) - F(a)
onde F'(x) = f(x)

Propriedades:
∫ₐᵇ f(x) dx = -∫ᵇₐ f(x) dx
∫ₐᶜ f(x) dx = ∫ₐᵇ f(x) dx + ∫ᵇᶜ f(x) dx
∫ₐᵇ [f(x) + g(x)] dx = ∫ₐᵇ f(x) dx + ∫ₐᵇ g(x) dx
```

**Aplicações Computacionais**

```bash
Análise de Algoritmos:
- Soma de séries: ∫ f(x) dx ≈ Σ f(i)
- Análise de complexidade média
- Probabilidade contínua

Métodos Numéricos:
- Regra do trapézio: ∫ₐᵇ f(x) dx ≈ (b-a)/2 [f(a) + f(b)]
- Regra de Simpson: maior precisão
- Integração Monte Carlo

Otimização:
- Cálculo de gradientes: ∇f = (∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂xₙ)
- Método do gradiente descendente
- Multiplicadores de Lagrange

Machine Learning:
- Funções de custo: minimização via cálculo
- Backpropagation: regra da cadeia
- Otimização de parâmetros

Processamento de Sinais:
- Transformada de Fourier: ∫ f(t)e^(-2πift) dt
- Convolução: (f * g)(t) = ∫ f(τ)g(t-τ) dτ
- Filtros digitais

Física Computacional:
- Equações diferenciais: modelagem de sistemas
- Simulação numérica: método de Euler
- Dinâmica de sistemas
```
