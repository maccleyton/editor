## 39.1 Fundamentos Matemáticos

---

### 39.1.1 Teoria da Probabilidade

- Estudo matemático da incerteza e eventos aleatórios.
- Define espaço amostral, eventos, probabilidade condicional, independência.
- Modela variáveis aleatórias, distribuições (Bernoulli, Normal, Binomial).
- Essencial para modelar dados incertos em machine learning.

---

### 39.1.2 Inferência Bayesiana

- Método para atualizar crenças sobre parâmetros/modelos dados novos dados.
- Usa Teorema de Bayes:
    
    $P(\theta | D) = \frac{P(D | \theta) P(\theta)}{P(D)}$
    

onde $\theta$ é o parâmetro e $D$ os dados.

- Permite incorporar conhecimento prévio e incertezas aos modelos.

---

### 39.1.3 Maximum Likelihood Estimation (Estimação por Máxima Verossimilhança)

- Técnica para estimar parâmetros do modelo que maximizam a probabilidade dos dados observados.
- Para dados $D$ e parâmetro $\theta$, busca $\hat{\theta} = \arg \max P(D|\theta)$.
- Base para muitos algoritmos clássicos de aprendizado supervisionado.

---

### 39.1.4 Teoria da Decisão

- Estudo formal para tomada de decisão sob incerteza.
- Baseia-se em funções de perda e risco esperado.
- Busca regra ótima que minimize o custo esperado de decisões.
- Fundamenta classificadores e algoritmos que equilibram erros e custos.

## 39.2 Algoritmos de Aprendizado

---

### 39.2.1 Variantes do Gradient Descent

- **Gradient Descent (GD):** Algoritmo iterativo para minimizar funções de custo, atualizado parâmetros na direção do gradiente negativo.
- **Batch Gradient Descent:** Usa todo o conjunto de dados para cada atualização; convergência estável, porém computacionalmente caro para grandes datasets.
- **Stochastic Gradient Descent (SGD):** Atualiza parâmetros baseado em uma amostra aleatória por iteração; mais rápido mas com ruídos nas atualizações.
- **Mini-Batch Gradient Descent:** Compromisso entre batch e SGD, usa pequenos lotes para atualizar os parâmetros; popular em treinamento de redes neurais.
- **Variantess Avançadas:** Momentum, AdaGrad, RMSprop, Adam, que adaptam taxas de aprendizado e aceleram convergência.

---

### Exemplo simplificado: Mini-batch Gradient Descent em Python

```python
import numpy as np

def mini_batch_gradient_descent(X, y, theta, lr=0.01, epochs=100, batch_size=32):
    m = len(y)
    for _ in range(epochs):
        indices = np.random.permutation(m)
        X_shuffled = X[indices]
        y_shuffled = y[indices]
        for i in range(0, m, batch_size):
            X_batch = X_shuffled[i:i+batch_size]
            y_batch = y_shuffled[i:i+batch_size]
            gradients = (1/len(y_batch)) * X_batch.T.dot(X_batch.dot(theta) - y_batch)
            theta -= lr * gradients
    return theta
```

### 39.2.2 Support Vector Machines (SVM)

- Algoritmo de classificação que busca o hiperplano que maximiza a margem entre classes.
- Utiliza otimização convexa para encontrar o melhor separador.
- Pode ser linear ou usar kernels para separar dados não lineares.

---

### 39.2.3 Decision Trees (Matemática)

- Modelo hierárquico que faz partições recursivas nos dados baseando-se em métricas de impureza (ex.: entropia, índice Gini).
- Árvores de decisão são construídas escolhendo os atributos que melhor separam os dados em cada nó.
- Matemática envolve cálculo de informações ganho e avaliação de splits.

---

### 39.2.4 Ensemble Methods

- Combinação de múltiplos classificadores ou regressores para melhorar performance.
- Técnicas incluem bagging, boosting e stacking.
- Exemplos populares: Random Forest (bagging de árvores), AdaBoost (boosting).

## 39.3 Redes Neurais Matemáticas

---

### 39.3.1 Teorema da Aproximação Universal

- Estabelece que uma rede neural feedforward com uma única camada oculta contendo número finito de neurônios pode aproximar qualquer função contínua em subconjuntos compactos de $\mathbb{R}^n$, dado função de ativação adequada (ex: sigmóide, ReLU).
- Não garante como encontrar os pesos ideais, apenas a existência.
- Implica que redes neurais têm poder expressivo universal para funções contínuas.
- Relevante para fundamentar uso de redes neurais em tarefas complexas.

---

### 39.3.2 Backpropagation Matemático

- Algoritmo de aprendizado que calcula gradientes da função de perda em relação aos pesos da rede.
- Baseado na regra da cadeia para derivadas parciais.
- Permite atualizar pesos via gradiente descendente de forma eficiente.
- Fundamental para treinamento de redes neurais profundas.

---

### 39.3.3 Optimization Landscapes

- Análise do espaço de soluções e funções de perda das redes neurais.
- Muitos mínimos locais e pontos de sela, mas experimentos mostram que redes profundas tendem a encontrar mínimos bons.
- Estudo das propriedades da superfície de perda auxilia no desenvolvimento de algoritmos de treinamento.

---

### 39.3.4 Regularização Matemática

- Técnicas para evitar overfitting e melhorar generalização.
- Exemplos incluem: penalização L1 (Lasso), L2 (Ridge), dropout, data augmentation.
- Envolve adicionar termos de custo na função objetivo ou modificar o processo de treinamento.

## 39.4 Teoria do Aprendizado

---

### 39.4.1 PAC Learning (Probably Approximately Correct)

- Estrutura formal proposta para analisar a aprendizagem a partir de dados finitos.
- Um conceito é PAC-aprendível se existe algoritmo que para todo $\varepsilon, \delta > 0$, com probabilidade pelo menos $1-\delta$, produz uma hipótese com erro menor que $\varepsilon$.
- Permite mensurar a quantidade mínima de dados necessários para aprender bem com alta confiança.
- Relaciona erros de generalização com tamanho do espaço de hipóteses e amostras.

---

### 39.4.2 VC Dimension (Vapnik-Chervonenkis)

- Medida da capacidade expressiva de um conjunto de hipóteses.
- Indica o maior número de pontos que pode ser "quebrado" (classificado de todas as formas) pelo modelo.
- Dimensão VC alta implica maior capacidade, mas mais risco de overfitting e necessidade de mais dados.
- Ligada a limites de generalização e erros.

---

### 39.4.3 Rademacher Complexity

- Medida de complexidade do conjunto de hipóteses baseada na capacidade de ajustar ruído aleatório.
- Ajuda a fornecer limites mais finos para o erro de generalização.
- Usada para comparar modelos e regularização.

---

### 39.4.4 Generalization Bounds (Limites de Generalização)

- Teoremas que relacionam erro empirico, capacidade do modelo (ex.: VC dimension), e número de amostras para garantir desempenho em dados novos.
- Fundamentais para entender como evitar sobreajuste.
