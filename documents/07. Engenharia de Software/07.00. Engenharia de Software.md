# **📌 Priorização das Optativas**

Como você pode escolher **duas**, priorizei com base na relevância técnica para a área de tecnologia:

### **⭐ Mais relevantes (escolha entre essas)**

1. **Programação de Software Básico em C** → Base fundamental para lógica e sistemas de baixo nível.
2. **Algoritmos e Complexidade** → Essencial para otimização de código e entrevistas técnicas.
3. **Desenvolvimento Rápido de Aplicações em Python** → Acelera a produtividade no desenvolvimento.
4. **Sistemas Distribuídos e Computação Paralela** → Fundamental para sistemas modernos escaláveis.

### **✅ Úteis, mas menos prioritárias**

1. **Aplicações de Cloud, IoT e Indústria 4.0 em Python** → Boa para quem pretende focar nessa área específica.
2. **Língua Portuguesa** → Útil para comunicação, mas não essencial para tecnologia.
3. **Educação Ambiental** → Mais voltada para conhecimento geral.
4. **Tópicos em Libras: Surdez e Inclusão** → Interessante para acessibilidade, mas opcional.
5. **Direitos Humanos** → Para um entendimento social mais amplo.
6. **História dos Povos Indígenas e Afrodescendentes** → Enriquecedor, mas não impacta diretamente na área técnica.

Se puder escolher **duas**, minha recomendação seria:
