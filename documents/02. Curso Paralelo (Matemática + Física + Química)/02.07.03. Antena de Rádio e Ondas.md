## 🎯 **Objetivo:**

Calcular tamanho da antena para frequência alvo.

**Fórmulas:**

1. Comprimento de onda:
    
    $\lambda = \frac{c}{f}$
    
    Com $c = 3\times10^8\ \mathrm{m/s}$.
    
2. Antena dipolo: $L = \lambda/2$.

**Exemplo:** Wi-Fi 2,4 GHz:

- $\lambda = 0,125\ \mathrm{m}$, dipolo ≈ 0,0625 m (6,25 cm).

**Extra:** simulação em Python do campo próximo:

```python
import numpy as np
import matplotlib.pyplot as plt

theta = np.linspace(0, 2*np.pi, 360)
E = np.abs(np.sin(theta))  # padrão dipolo
plt.polar(theta, E)
plt.title("Padrão de radiação de um dipolo")
plt.show()
```
