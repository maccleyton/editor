## 23.1 Conceito de Backtracking

- Backtracking é uma técnica de solução de problemas baseada em tentativa e erro.
- O algoritmo explora recursivamente o espaço de soluções possíveis, construindo uma solução passo a passo.
- Quando um caminho não leva à solução, o algoritmo "retrocede" (faz backtrack) para tentar outra alternativa.
- Muito usado em problemas de combinação, permutação, busca em jogos, labirintos, e satisfabilidade de restrições.

---

## 23.2 Estrutura Geral

---

### 23.2.1 Espaço de Soluções

- Representado como uma árvore de decisão onde cada nó corresponde a uma escolha de valores para parte da solução.
- A busca explora esse espaço, tentando tomar decisões válidas até encontrar solução completa.

---

### 23.2.2 Poda (Pruning)

- Técnica para cortar ramos da árvore de busca que não levarão a soluções válidas.
- Evita exploração desnecessária e reduz complexidade combinatória.
- Exemplo: em Sudoku, preencher um número que viola regras pode ser imediatamente descartado.

---

### 23.2.3 Função de Validação

- Função que determina se a solução parcial atual é válida e pode continuar a ser explorada.
- Fundamental para garantir que o algoritmo não explore caminhos inviáveis.

---

### Exemplo prático: Gerar todas as permutações de uma lista

```python
def permutacoes(lista):
    resultado = []

    def backtrack(caminho, restantes):
        if not restantes:
            resultado.append(caminho)
            return
        for i in range(len(restantes)):
            novo_caminho = caminho + [restantes[i]]
            nova_lista = restantes[:i] + restantes[i+1:]
            backtrack(novo_caminho, nova_lista)

    backtrack([], lista)
    return resultado

*# Exemplo de uso*
itens = [1, 2, 3]
perms = permutacoes(itens)
for p in perms:
    print(p)
```

## 23.3 Problemas Clássicos com Backtracking

---

### 23.3.1 N-Queens

- Objetivo: posicionar $N$ rainhas em um tabuleiro $N \times N$ sem que nenhuma ataque a outra.
- Backtracking consiste em colocar uma rainha por vez, validando linhas, colunas e diagonais.
- Retrocede quando não há posição válida.

---

### 23.3.2 Sudoku Solver

- Resolver sudoku preenchendo as células vazias com números válidos segundo regras.
- Backtracking testa possibilidades e retrocede se conflito for detectado.
- Utilizado como exemplo clássico em inteligência artificial.

---

### 23.3.3 Problema do Labirinto

- Encontrar caminho do ponto inicial até a saída no labirinto representado por matriz.
- Backtracking explora caminhos possíveis e volta quando encontra beco sem saída.

---

### 23.3.4 Subset Sum

- Dado um conjunto de números e um valor alvo, determinar se há um subconjunto cuja soma seja igual ao alvo.
- Backtracking explora inclusão e exclusão de elementos para formar soma desejada.

---

## 23.4 Otimizações em Backtracking

---

### 23.4.1 Heurísticas de Poda

- Estratégias para eliminar ramos improdutivos antecipadamente.
- Exemplo: no sudoku, verificar linhas, colunas e blocos antes de tentar valores.

---

### 23.4.2 Ordenação de Variáveis

- Ordenar variáveis para testar primeiro as que têm maior restrição.
- Pode reduzir espaço de busca explorado drasticamente.

---

### 23.4.3 Forward Checking

- Técnica que mantém controle das possibilidades futuras antes de tomar decisões.
- Elimina valores dos domínios das variáveis relacionadas, antecipando conflitos.

---

### Exemplo Python: N-Queens Simplificado

```python
def n_queens(n):
    soluções = []
    tabuleiro = [-1] * n  *# tabuleiro[i] = coluna da rainha na linha i*

    def é_valido(linha, coluna):
        for i in range(linha):
            if tabuleiro[i] == coluna or \
            abs(tabuleiro[i] - coluna) == abs(i - linha):
                return False
        return True

    def backtrack(linha=0):
        if linha == n:
            soluções.append(tabuleiro[:])
            return
        for coluna in range(n):
            if é_valido(linha, coluna):
                tabuleiro[linha] = coluna
                backtrack(linha + 1)

    backtrack()
    return soluções

print(n_queens(4))
```
